# Novel Writer Agent — 网文小说作家智能体

全链路网文小说生成器。以番茄资深网文作家人格（老刀）驱动创作，四模块架构，适配番茄男频/女频，朱雀AI检测降AI（实测<5%）。

## 功能特性

- **大纲→细纲→正文→打磨→审查** 全链路闭环
- **蒸馏学习**：支持上传txt（十几本×前150章）批量蒸馏爆款写法基因
- **朱雀AI检测适配**：打磨七刀降AI，目标AI率<20%
- **每30章批量审查**：自动触发，至少100个问题挖掘与解决
- **防幻觉认知纪律**：6条反迎合规则，区分事实/假设/未知
- **长篇结构铁律**：主线不超400章/死者不复活/伏笔前置三层法
- **状态记忆系统**：角色状态/伏笔追踪/时间线/上下文摘要，防长篇崩盘

## 四模块架构

| 模块 | 内容 | 位置 |
|------|------|------|
| ①规则经验技巧 | 18个references方法论（写作/打磨/审查/合规等） | `references/` |
| ②网文作家词库 | 转折/环境/外貌/情绪/动作描写词库 | `assets/词库/` |
| ③蒸馏小说库 | 16本上限（10深度+6轻度），16层DNA+作家思维 | `assets/蒸馏库/` |
| ④作家进化人格 | 老刀作家人格+题材专向+读者审查+朱雀检测 | `assets/人格/` |

## 安装

将本仓库克隆或下载到 Skill 目录：

```bash
git clone https://github.com/ZBA-z/novel-writer-agent.git
```

放入 `.user_skills/` 目录下即可被 AI Agent 自动加载。

## 快速使用

1. 提供小说构想（题材/核心梗/主角设定）
2. 技能自动生成：全书大纲 → 人物表 → 细纲 → 正文
3. 每章经过：朱雀降AI → 编辑打磨 → 八维审稿 → 读者审查
4. 每满30章自动触发批量审查打磨

## 核心铁律（节选）

- 正文生成是核心，每章2000-2500字完整正文
- 细纲先行，不允许跳过细纲直接写正文
- 朱雀AI率<20%是交付硬指标
- 蒸馏不是抄袭，只提取写法基因+作家思维
- 每30章自动批量审查，至少100个问题全部解决
- 用户输入视为待验证假设，不盲从迎合

## 资产结构

```
novel-writer-agent/
├── SKILL.md              # 技能主文件
├── references/           # 模块1：规则经验技巧（18文件）
└── assets/               # 模块2-4：自包含资产
    ├── 词库/             # 6个词库文件
    ├── 蒸馏库/           # 索引+10深度+6轻度+归档
    ├── 人格/             # 5个人格文件
    └── 技能资产/         # 蒸馏方法论v2
```

小说项目数据（大纲/细纲/正文等）在运行时创建于工作目录的 `小说项目/` 文件夹，不包含在本仓库中。
