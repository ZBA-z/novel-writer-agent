# Novel Writer Agent

全链路网文小说生成器。以番茄资深网文作家人格驱动创作，四模块架构，适配番茄男频/女频，朱雀AI检测降AI。

## 功能特性

- 大纲到正文全链路闭环
- 蒸馏学习：支持上传txt批量蒸馏爆款写法基因
- 朱雀AI检测适配：打磨七刀降AI，目标AI率<20%
- 每30章批量审查：自动触发，至少100个问题挖掘与解决
- 防幻觉认知纪律：6条反迎合规则
- 长篇结构铁律：主线不超400章/死者不复活/伏笔前置
- 状态记忆系统：角色状态/伏笔追踪/时间线

## 四模块架构

1. 规则经验技巧：18个references方法论
2. 网文作家词库：转折/环境/外貌/情绪/动作
3. 蒸馏小说库：16本上限，16层DNA+作家思维
4. 作家进化人格：老刀+题材专向+读者审查+朱雀检测

## 安装

git clone https://github.com/ZBA-z/novel-writer-agent.git

放入 .user_skills/ 目录即可加载。

## 快速使用

1. 提供小说构想（题材/核心梗/主角设定）
2. 自动生成：大纲 -> 人物表 -> 细纲 -> 正文
3. 每章经过：朱雀降AI -> 编辑打磨 -> 八维审稿 -> 读者审查
4. 每满30章自动批量审查

## 核心铁律

- 正文生成是核心，每章2000-2500字
- 细纲先行，不跳过细纲写正文
- 朱雀AI率<20%是交付硬指标
- 蒸馏不是抄袭，只提取写法基因
- 每30章自动批量审查，100问题全解决
- 用户输入视为待验证假设，不盲从
