# 网文作家词库管理规范

> 用途：管理从蒸馏小说和网络资源中收集的网文常用词、转折词、经典描写词，确保词库质量，避免模板化。
> 核心原则：词库是"灵感参考"而非"强制模板"。调用词库的目的是丰富表达，不是机械替换。与降AI冲突时，降AI优先。

---

## 一、词库定位

| 场景 | 调用方式 | 原因 |
|------|---------|------|
| 外貌描写 | **强制参考** | 最容易写得干瘪/重复，词库能显著提升质量 |
| 环境描写 | **强制参考** | 氛围营造依赖具体意象，词库提供多样化选择 |
| 战斗/动作描写 | **强制参考** | 动作词容易重复（"一拳打出""一脚踹出"），词库提供变化 |
| 转折/过渡 | **强制参考** | "突然""然而"滥用是AI特征，词库提供多样化转折 |
| 情绪描写 | **参考** | 情绪需要结合上下文，直接调用容易模板化 |
| 对话 | **不调用** | 对话必须角色驱动，调用词库会导致所有角色说话一个味 |
| 心理描写 | **不调用** | 心理必须贴合角色性格，词库化会增加AI味 |
| 叙事/转折 | **参考** | 可参考但不强制，避免叙事节奏被词库锁死 |

---

## 二、入库标准（什么词值得收）

### 2.1 必要条件（全部满足才能入库）
1. **画面感**：词或短语能唤起具体视觉/听觉/触觉意象，不是抽象形容词
2. **非通用**：不是"很好看""很可怕"这种白开水词，有独特性
3. **可复用**：不依赖特定小说的人名/地名/设定，换一本书也能用
4. **非AI套话**：不是"眼中闪过一丝""嘴角勾起一抹"这种被AI用烂的词

### 2.2 优先收录（满足任意一条）
- 在3本以上爆款小说中出现过的高频表达
- 有独特感官通道的词（如"铁锈味的风""玻璃碴似的笑声"）
- 能替代AI高频词的表达（如用"话音未落"替代"突然"）
- 有情绪色彩的中性词（如"死寂"比"安静"更有张力）

### 2.3 禁止收录
- AI套话清单中的所有表达（见anti-ai-detection.md）
- 过于生僻/文言的词（番茄读者看不懂）
- 依赖特定设定的专有名词
- 低俗/违规/敏感词

## 四、词库条目格式

每个词条按以下格式存储：

```
### [词条]
- **类型**：[动词/形容词/短语/意象]
- **适用场景**：[什么情况下用]
- **情绪色彩**：[正面/负面/中性/紧张/舒缓]
- **替换目标**：[这个词可以替代什么白开水词/AI套话]
- **示例**：[在句子中的用法]
- **来源**：[从哪本小说/哪个资源蒸馏得到，"通用"表示网络公开资源]
- **使用频率**：[高/中/低]——高频词注意不要连续使用
```

## 五、筛查机制（每次蒸馏时执行）

### 5.1 从蒸馏文本中提取候选词
1. 通读文本，标记有画面感的词/短语
2. 按分类归入候选区
3. 对照入库标准逐条筛选

### 5.2 去重
- 新词与现有词库比对，语义重复的不收录
- 近义词保留最有画面感的1-2个，不堆砌同义词

### 5.3 质量评估
- 每个新词标注"置信度"（高/中/低）
- 低置信度词放入"待验证区"，在后续生成中测试效果后决定是否正式收录

### 5.4 淘汰机制
- 每季度审查一次词库
- 连续3次生成中被判定为"增加AI味"的词，移入"慎用区"
- 被朱雀检测标记为AI高频特征的词，立即移入"禁用区"

## 六、调用规则（写作时）

1. **写前查阅**：写外貌/环境/战斗/转折场景前，快速浏览对应词库
2. **不照抄**：词库提供的是"灵感方向"，不是"填空模板"。结合具体场景调整
3. **变化使用**：同一章内不重复使用词库中的同一个高频词
4. **降AI优先**：如果用了词库的词导致句式均匀/模板化，立即放弃，用更自然的表达
5. **记录反馈**：生成后审查时，记录哪些词用得好、哪些词显得生硬，反馈给词库管理

## 八、与降AI的冲突解决

词库和降AI存在内在张力：词库用多了→模板化→AI率升高。解决原则：

1. **词库是"调料"不是"主菜"**：一章中词库词占比不超过15%
2. **优先用"意象"而非"形容词"**："铁锈味的风"比"阴森的风"更不容易被判定为AI
3. **每次调用后检查句式**：如果用词库词后句子变得"工整均匀"，打乱句式
4. **词库词必须搭配1字句/短句使用**：长句+词库词=AI，短句+词库词=人味
