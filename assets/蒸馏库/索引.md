## 五、题材通用写法基因（多书融合后提取）

### 灵异恐怖类（D009+D001+D004融合）
- **开篇公式**：日常切入（论坛/学校/生活）→ 诡异事件暗示 → 主角卷入 → 发现规律/能力
- **氛围营造**：用具体细节制造恐怖（体温/第五副碗筷/脚步声），不用"阴森恐怖"形容词；用声音/留白/日常反差
- **节奏模式**：慢热恐怖型，靠悬念和氛围维持，5章一小爽（规律破解）
- **核心禁忌**：不堆砌世界观，鬼的规律需要主角和读者一起推理；爽点是"找到规律"不是"打败鬼"

### 末世诡异类（D011+D010+D003+L007融合）
- **开篇公式**：逃亡现场/困境现场（掉队=死/底层/被追杀）→ 末世世界观碎片（天空炸了/诡异涌现/资源稀缺）→ 金手指/序列觉醒
- **氛围营造**：用经济细节（光源涨价/物资分配）和逃亡压力建立末世压迫感，环境服务生存压力
- **节奏模式**：快节奏求生型，2-3章一小爽+8-10章一中爽+25-30章一大爽
- **力量体系**：序列/祭物/湮物/禁区+克制手段，量化给读者明确升级预期
- **物资升级爽点**：从杀猪刀到幽冥骨车，装备升级是持续爽点

### 无限流副本类（L005+L006+L008融合）
- **结构公式**：进入副本→规则/任务宣布→探索→解谜/博弈/战斗→破局逃生→回归奖励→新副本
- **核心张力**：规则限制+信息差+死人压力，智斗/解谜/战斗驱动
- **爽点结构**：长压抑（副本危险）→ 线索拼凑/识破骗局/战斗爆发 → 真相揭晓/反杀 → 逃生/奖励
- **开篇模式**：密室/无司机大巴/多人醒来/复仇现场，直接进入生存场景
- **杀伐战斗**：关键招+结果+反应，快慢交替，不圣母不废话

### 都市高武/异能类（D002+D003融合）
- **开篇公式**：路人视角切入+反差画面 → 建立人设 → 第一个诡异/战斗事件
- **人物塑造**：对话驱动，每个角色说话方式不同，配角群像
- **爽点结构**：短压抑+能力触发+可视化战斗+情感落点
- **节奏**：3章一小爽+10章一中爽+30章一大爽

### 升级流通用（D011+D010融合）
- **开篇公式**：极压抑底层场景（逃亡/掉队/没钱）→ 金手指/序列觉醒 → 第一次反杀/升级
- **反馈机制**：即时反馈感强（物资升级/祭物获得/序列觉醒）
- **节奏**：2-3章一小爽，章章有进展
- **人设**：普通人+务实狠辣+吐槽，不圣母但有底线

### 文笔/人物学习（D008）
- 文言白话融合，对话有江湖气
- 留白手法，情感不直说
- 配角群像天花板，每个角色有独立弧光
- 章名诗意，用意象传情

## 六、检索规则

生成小说时，按以下规则检索蒸馏库：

1. **题材匹配**：根据当前小说的题材标签，匹配同题材的蒸馏档案
2. **深度优先**：同题材有深度蒸馏的，优先读取深度档案
3. **数量限制**：每次生成最多读取2-3本蒸馏档案，避免基因冲突
4. **通用调用**：题材通用写法基因可跨题材调用（如开篇公式/钩子技法）
5. **无匹配时**：如果蒸馏库中没有同题材档案，使用通用番茄男频写法标准（基于行业经验）
6. **末世诡异题材推荐组合**：D011（末世序列车队/物资升级爽点）+ D009（灵异恐怖氛围/规律破解）+ D002（节奏/人物群像）
7. **无限流/副本题材推荐组合**：L008（杀伐战斗）+ L005（智斗/心理博弈）+ L006（副本结构/解谜）

## 七、入库流程

用户上传txt后：

1. **分类**：按题材分类
2. **筛选**：每类选2-3本最有代表性的做深度蒸馏，其余轻度
3. **蒸馏**：按 `D:\番茄小说\技能资产\蒸馏方法论v2.md` 执行
4. **存档**：DNA档案保存到 `深度蒸馏/` 或 `轻度蒸馏/` 目录
5. **更新索引**：在本文件中登记
6. **词库筛查**：从蒸馏文本中筛查词汇素材，追加到对应词库
7. **满员处理**：超过12本时，替换可复用度最低的旧本，移入 `归档/`

## 八、淘汰与更新

- **每季度审查**：检查蒸馏库中的档案是否过时/冲突
- **可复用度更新**：每次生成后记录哪些基因用得好，更新可复用度评分
- **淘汰标准**：连续3次生成未被调用/可复用度低/与其他档案基因冲突
- **淘汰记录**：淘汰的档案移入 `归档/` 目录，不直接删除，可恢复
