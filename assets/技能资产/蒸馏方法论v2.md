# 蒸馏学习方法论 v2.0（Distillation Method v2）

> 用途：从用户上传的小说txt（一次十几本×前150章）中深度蒸馏"写法基因+作家思维+词汇素材"，用用户自己的设定重新实现，不抄袭。
> 核心原则：蒸馏的是"怎么写"和"为什么这么写"，不是"写了什么"。学书法——临摹笔法结构，然后写自己的内容。
> v2.0升级：从六维度扩展为16层DNA+作家思维维度，支持大规模语料批量蒸馏，新增词库筛查和蒸馏库管理。

## 零、蒸馏库规模与管理

### 0.1 最佳规模（经过调研确定）

| 层级 | 数量 | 单本DNA档案字数 | 用途 |
|------|------|----------------|------|
| 深度蒸馏 | 8本上限 | 3000-5000字/本 | 核心对标，每章细读，16层DNA全提取 |
| 轻度蒸馏 | 4本上限 | 1000-2000字/本 | 补充参考，只提取核心节奏和爽点模式 |
| **总计** | **12本上限** | — | 超过12本会导致检索困难和基因冲突 |

**为什么是12本？**
- 学术研究（NovelDreamer/GRPO风格迁移）表明：3-5本同题材作品足以提炼稳定的风格基因
- 超过12本后，不同作者的写法基因会冲突（A书的节奏和B书的节奏矛盾），导致"精神分裂"
- 每本DNA档案3000字，12本=36000字，一次生成时检索2-3本相关题材=6000-9000字，在上下文可承受范围内
- 深度蒸馏8本覆盖主要题材方向，轻度4本做补充

### 0.2 蒸馏库分类与检索

每本蒸馏档案标注：
- **题材标签**：末世诡异/都市异能/玄幻修仙/系统流/规则怪谈/...
- **蒸馏深度**：深度/轻度
- **核心基因**：节奏模式/爽点类型/人设反差/对话风格（一句话概括）
- **可复用度**：高/中/低

**检索规则**：
- 生成时按题材标签自动匹配2-3本最相关的蒸馏档案
- 同题材深度蒸馏优先，轻度补充
- 通用技巧（开篇公式/钩子技法）可跨题材调用
- 每次生成不超过3本蒸馏档案，避免基因冲突

### 0.3 蒸馏库更新规则
- 用户上传新txt → 蒸馏后评估是否入库存档
- 已有12本时，新本替换"可复用度最低"的旧本
- 每季度审查蒸馏库，淘汰过时/冲突的档案
- 每次生成后记录"哪些基因用得好"，反馈到蒸馏档案的"可复用度"评分

## 一、蒸馏 vs 抄袭的边界（不变）

| 维度 | 可蒸馏（学） | 不可触碰（抄） |
|------|-------------|---------------|
| 节奏 | 爽点频率/章节长度/情绪曲线波形 | 具体剧情序列（先遇A再打B再去C） |
| 人设 | 反差模式/性格矛盾感/记忆点设计 | 具体人名/外貌/背景故事 |
| 爽点 | 爽点类型/触发结构/反应镜头用法 | 具体桥段/标志性台词/标志性场景 |
| 对话 | 语言风格/潜台词手法/角色区分度 | 具体台词内容 |
| 设定 | 力量体系的量化思路/世界观架构 | 独特设定组合（别人的核心卖点） |
| 开篇 | 开场模式/钩子类型/信息释放节奏 | 具体开篇场景/第一句话 |
| 作家思维 | 决策逻辑/信息控制/情绪算法 | 具体的情节选择 |

**判断法**：把对标书的角色名/地名/功法名全部替换成"主角A/反派B/城市X"后，如果你的故事和它还能对得上每一个情节节点，那就是抄袭。如果只是节奏和爽点类型相似，那就是蒸馏。

## 二、大规模语料蒸馏工作流（十几本×150章）

用户一次上传十几本小说的前150章，按以下流程批量处理：

### 第一步：分类与筛选
1. 按题材分类（末世/都市/玄幻/系统/...）
2. 每类选2-3本最有代表性的做深度蒸馏，其余做轻度蒸馏
3. 深度蒸馏总数不超过8本，轻度不超过4本
4. 超出12本的，记录书名但暂不蒸馏，等蒸馏库有空位再处理

### 第二步：单本深度蒸馏（8步+16层DNA）
对每本深度蒸馏的小说，执行：

#### 第1步：通读与整体感受
- 以读者身份快速通读前10章，记录整体感受
- 标注：这本书最吸引人的地方是什么？最想吐槽的地方是什么？
- 输出：一句话整体评价 + 核心卖点

#### 第2步：骨架拆解（全书/前150章）
- 每章用一句话概括核心事件（50-100字）
- 标注每章的爽点位置和类型
- 标注每章的章尾钩子类型
- 绘制节奏曲线：小爽点/中高潮/大高潮的分布
- 输出：章节节奏表 + 高潮分布图

#### 第3步：黄金三章专项拆解
- 第1章：开篇钩子类型/前300字内容/金手指激活方式/章尾钩子
- 第2章：金手指展示/冲突升级/成长获取
- 第3章：第一个完整爽点/目标确立/大钩子
- 输出：黄金三章拆解表

#### 第4步：16层DNA提取（核心）
按以下16层逐章/逐段分析：

**叙事引擎层（靠什么驱动读者翻页）**
1. 核心驱动力：悬念/爽感/情感/好奇/恐惧——哪种为主？
2. 信息释放节奏：一次给多少，留多少？读者知道多少vs角色知道多少？
3. 悬念管理：怎么挖坑、怎么填、填的时机？

**场景架构层**
4. 单章结构：开头/升级/转折/收尾的固定模式
5. 场景切换频率和方式
6. 章首钩子7式中常用哪几种？章尾钩子13式中常用哪几种？

**语言纹理层**
7. 句法节奏：句子长度分布/长短句比例/段落长度
8. 用词偏好：高频词/独特用词/比喻来源（从哪类事物取比喻）
9. 修辞多样性：比喻/拟人/夸张/通感的使用频率

**对话系统层**
10. 对话轮次长度：平均几句一轮？
11. 潜台词手法：话里有话还是直说？
12. 权力动态：对话中谁占上风？怎么体现？
13. 提示语风格：用"他说"还是用动作/表情？

**内心戏层**
14. 内心戏方式：直接思想/自由间接体/身体反应代替心理——哪种为主？

**意象与母题层**
15. 反复出现的物体/感官通道/颜色/意象

**情感算法层**
16. 情绪如何升起、伪装、转移、释放？情绪曲线波形？

#### 第5步：人设与角色行为语法
- 主角：身份/金手指反差/性格矛盾感/记忆点/决策模式
- 反派：动机/能力/不降智的体现/失败原因
- 配角：功能/区分度/成长线
- 角色行为语法：面对压力时的反应模式/说话风格/决策逻辑

#### 第6步：爽点模式深度拆解
- 主爽点类型及占比
- 爽点四段式（压抑→触发→爆发→余韵）的具体实现方式
- 反应镜头用法：旁人震惊/反派变脸/群众哗然的分层
- 爽点之间的填充内容：悬念/新设定/人物冲突/日常
- 叙事能量守恒：前期压抑值×伏笔密度＝后期爆发强度

#### 第7步：作家思维提取（v2.0新增）
这是最关键的一层——不只是"写了什么"，而是"作者为什么这么写"：
- **决策逻辑**：主角在关键节点为什么选A不选B？作者的取舍标准是什么？
- **信息控制**：作者什么时候让读者知道真相？什么时候隐瞒？为什么？
- **情绪操控**：作者想让读者在这一章感受到什么？用了什么手段？
- **节奏直觉**：为什么在这里放慢？为什么在这里加速？
- **读者预期管理**：作者怎么利用/颠覆读者的预期？
- **商业意识**：哪些地方是为了追读率/留存率设计的？

#### 第8步：词汇素材筛查（v2.0新增）
- 通读中标注有画面感的词/短语
- 按词库分类（转折/环境/外貌/情绪/动作）归入候选
- 对照词库入库标准筛选
- 去重后追加到对应词库文件
- 标注来源（本书名）

### 第三步：轻度蒸馏（4本）
对轻度蒸馏的小说，只执行：
- 第1步（整体感受）
- 第2步（骨架拆解，只拆前30章）
- 第4步的16层DNA中只提取：1/4/7/10/16（核心驱动力/单章结构/句法节奏/对话轮次/情感算法）
- 第6步（爽点模式，简化版）
- 输出：1000-2000字的精简DNA档案

### 第四步：多书融合
1. 同题材的深度蒸馏书对比，找出共性（多本书都用的模式=行业验证的有效模式）
2. 找出差异（每本书的独特长处）
3. 融合：共性基因全部采纳，差异基因择优采纳
4. 标注每段基因来自哪本书，方便追溯
5. 形成"题材通用写法基因"（存放在蒸馏库索引中）

**融合原则**：不是简单拼接，而是"以一本书的基因为主框架，其他书的长处做补强"。同时学3本书的节奏会精神分裂。

## 三、写法基因报告模板（深度蒸馏）

```

基本信息：
- 题材：[标签]
- 蒸馏深度：深度/轻度
- 蒸馏范围：前XX章
- 可复用度：高/中/低
- 一句话核心卖点：[这本书最吸引人的地方]

1. 叙事引擎DNA
   - 核心驱动力：[悬念/爽感/情感/好奇/恐惧]
   - 信息释放节奏：[一次给多少，留多少]
   - 悬念管理：[挖坑/填坑的节奏]

2. 场景架构DNA
   - 单章结构模式：[开头/升级/转折/收尾]

   - 章尾钩子常用：[13式中的哪几种]

3. 语言纹理DNA
   - 句法节奏：[句子长度分布/长短句比例]

   - 修辞特点：[比喻/拟人/通感的使用]

4. 对话系统DNA
   - 对话轮次：[平均几句一轮]
   - 潜台词手法：[话里有话/直说]
   - 权力动态：[谁占上风，怎么体现]
   - 提示语风格：[他说/动作/表情]

5. 内心戏DNA
   - 主要方式：[直接思想/自由间接体/身体反应]

6. 意象与母题DNA
   - 反复出现的意象：[物体/感官/颜色]

7. 情感算法DNA
   - 情绪曲线波形：[压抑→小爽→大压抑→大爽→新悬念]
   - 情绪释放方式：[爆发/隐忍/转移]

8. 人设DNA
   - 主角反差模式：[身份vs能力]
   - 性格矛盾感：[具体矛盾组合]
   - 记忆点设计：[口头禅/习惯/标签]
   - 决策模式：[面对选择时怎么选]

9. 爽点DNA
   - 主爽点类型：[打脸/升级/反杀/收服/...]
   - 爽点结构：[压抑怎么铺/触发用什么/爆发怎么演/余韵怎么收]
   - 反应镜头用法：[具体模式]
   - 节奏规律：[X章一小爽，X章一中爽，X章一大爽]

10. 开篇DNA
    - 开场类型：[高能画面/冲突现场/反常悬念/...]
    - 前500字建立：[危机/人设/悬念]
    - 首爽点位置：第X章

11. 世界观DNA
    - 设定交代方式：[事件驱动/旁白解说/对话透露]
    - 信息释放节奏：[一次给多少]
    - 力量体系量化：[等级制/数值制/对比制]

12. 作家思维DNA（v2.0核心新增）
    - 决策逻辑：[主角关键选择的取舍标准]
    - 信息控制：[什么时候让读者知道真相]
    - 情绪操控：[想让读者感受到什么，用了什么手段]
    - 节奏直觉：[哪里放慢/哪里加速，为什么]
    - 读者预期管理：[怎么利用/颠覆预期]
    - 商业意识：[哪些设计是为了追读率/留存率]

13. 可复用骨架
    - 节奏模式：[X章一大爽+X章一小爽]
    - 爽点结构：[具体的四段式实现方式]
    - 人设反差：[底层身份+独占金手指+反转对比]
    - 开篇模式：[冲突现场开场+3章内首爽]

14. 需规避元素（原作独创）
    - 具体设定组合：[别人的核心卖点]
    - 标志性桥段：[具体剧情序列]
    - 标志性台词：[原作独有的句子]

15. 词汇素材贡献
    - 从本书筛查入库的词：[分类+数量]
    - 本书独特的表达风格：[一句话]

16. 蒸馏质量自评
    - 置信度：[高/中/低]
    - 哪些维度信息不足：[标注]
    - 建议与哪些书的基因融合使用
```

## 四、防抄袭红线（不变）

1. 不照搬人名、地名、功法名、组织名
2. 不照搬具体桥段序列
3. 不照搬独特的设定组合
4. 不照搬标志性台词和标志性场景
5. 对标作品还在连载/热门时，额外注意避免过于相似
6. 蒸馏结果中必须明确区分"可复用骨架"和"需规避元素"
7. 如果用户要求"写得和XX一模一样"，必须拒绝并解释抄袭风险

## 五、蒸馏质量自检

- [ ] 16层DNA都提取了？（深度蒸馏）
- [ ] 作家思维DNA提取了？（决策逻辑/信息控制/情绪操控/节奏直觉）
- [ ] 写法基因是抽象模式，不是具体内容？
- [ ] 明确标注了可复用和需规避？
- [ ] 多书融合时有主框架，不是简单拼接？
- [ ] 词汇素材筛查了？按分类归入词库？
- [ ] 对标书的具体内容（人名/地名/桥段）没有出现在基因报告中？
- [ ] 蒸馏档案字数在3000-5000字（深度）或1000-2000字（轻度）？
- [ ] 题材标签和可复用度标注了？
- [ ] 如果把对标书的角色名替换掉，你的故事和它不会逐节点对应？

## 六、蒸馏与创作的注入关系

蒸馏完成后，写法基因注入后续所有环节：

| 创作环节 | 注入哪些DNA |
|---------|------------|
| 大纲架构 | 叙事引擎DNA/节奏DNA/情感算法DNA/作家思维DNA |
| 人物表 | 人设DNA/角色行为语法 |
| 细纲 | 场景架构DNA/爽点DNA/钩子DNA |
| 正文写作 | 语言纹理DNA/对话DNA/内心戏DNA/意象DNA |
| 打磨 | 全部DNA对照检查 |
| 审查 | 可复用骨架vs需规避元素的边界检查 |
| 词库调用 | 从本书筛查的词汇素材 |

## 七、调研来源

- Works DNA Extractor（GitHub）：16层DNA提取框架
- 网文拆书八步法：选目标→明确目的→通读两遍→拆大纲章纲→分析叙事时间线→剖析人设→理清感情线→总结核心技巧
- 叙事能量守恒公式：前期压抑值×伏笔密度＝后期爆发强度
- 节奏规律：3章一小爽，10章一中爽，50章一大爽
- NovelDreamer（学术）：RAG检索增强风格一致性
- GRPO风格迁移（学术）：风格相似度judge+强化学习微调
