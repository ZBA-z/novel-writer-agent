# 续写小说流程（Continuation Guide）
> 用途：用户已有小说正文，要求续写后续章节。续写和从零创作完全不同，必须先分析已有内容再续写。

---

## 一、续写 vs 从零创作的区别

| 维度 | 从零创作 | 续写 |
|------|----------|------|
| 设定 | 自己建立 | 必须从已有内容中提取 |
| 人物 | 自己设计 | 必须匹配已有角色的性格/语言/习惯 |
| 文风 | 自己定 | 必须匹配已有文本的语气/句式/节奏 |
| 剧情 | 自己规划 | 必须承接已有剧情，不能矛盾 |
| 伏笔 | 自己埋设 | 必须先找出已有伏笔，不能冲突 |

**核心原则：续写不是"接着写"，是"先学习再模仿"。**

---

## 二、续写五步流程

### 第一步：读取已有内容（必做，不能跳过）

**用户提供了什么？**
- 完整文本文件 → 全部读取
- 部分章节 → 读取提供的所有章节
- 只有简介/大纲 → 按简介/大纲续写，但要标注"基于有限信息续写"

**读取后必须提取的信息：**
1. **世界观设定**：力量体系/地理/势力/规则（从正文中提取，不是用户说的）
2. **角色信息**：每个出场角色的性格/语言风格/口头禅/能力/关系
3. **当前状态**：主角在哪/什么状态/最近发生了什么/有什么未解决的冲突
4. **文风特征**：句式长短/用词习惯/对话风格/叙事视角/节奏快慢
5. **已有伏笔**：埋了什么还没回收的

**输出**：`续写分析报告.md`，包含以上5项。

### 第二步：建立人物表（基于已有内容）

**不要自己设计人物**，从已有文本中提取：
- 角色说了什么话？（语言风格）
- 角色做了什么事？（性格/动机）
- 角色和其他人怎么互动？（关系）
- 角色有什么口头禅/小动作？（记忆点）

**如果已有内容中角色信息不足**：
- 标注"信息不足，基于已有表现推断"
- 不要凭空添加角色背景/能力/关系

**输出**：`设定/人物表.md`（基于已有内容提取版）

### 第三步：匹配文风（关键！）

续写最大的失败是"文风突变"，读者一眼就能看出来不是同一个人写的。

**文风匹配检查清单：**
- [ ] 叙事视角一致？（第一人称/第三人称/上帝视角）
- [ ] 句式长度匹配？（原文短句多还是长句多）
- [ ] 用词习惯匹配？（口语化/书面化/方言/专业术语）
- [ ] 对话风格匹配？（角色说话方式一致）
- [ ] 节奏匹配？（原文快节奏还是慢节奏）
- [ ] 描写密度匹配？（原文心理描写多还是动作描写多）
- [ ] 系统提示格式匹配？（如果是系统文，【】格式/提示风格一致）

**文风匹配方法：**
1. 选取原文最后3章，逐段分析文风特征
2. 写一段200字的试写，和原文对比
3. 调整到"放在原文里不突兀"的程度
4. 再开始正式续写

### 第四步：规划续写内容

**先确认续写起点：**
- 从哪一章开始续写？
- 上一章结尾是什么？（必须承接）
- 用户有没有指定续写方向？

**然后规划：**
- 短期目标：接下来3-5章发生什么
- 中期目标：接下来1卷（30章）的核心冲突
- 承接已有伏笔：哪些伏笔需要在续写中回收
- 新伏笔埋设：续写中可以埋什么新伏笔

**输出**：续写细纲（按正常细纲8要素）

### 第五步：续写正文+打磨+审查

和正常正文写作流程一样：
1. 按细纲写正文（2000-2500字/章）
2. 七刀打磨
3. 八维审查
4. 更新追踪文件

**额外检查：文风一致性**
- 写完后和原文最后一章对比，文风是否一致？
- 角色说话方式是否和原文一致？
- 有没有引入原文没有的设定/能力/关系？

## 三、续写的特殊规则

### 3.1 绝对不能做的事
1. **不能改已有设定**：原文说主角是F级，续写不能突然变成S级
2. **不能改已有角色性格**：原文角色是冷静的，续写不能变成话痨
3. **不能否定已有剧情**：原文某人死了，续写不能让他复活（除非原文有伏笔）
4. **不能突然切换文风**：原文是短句快节奏，续写不能变成长句慢节奏
5. **不能加原文没有的核心设定**：原文没有系统，续写不能突然加系统

### 3.2 可以做的事
1. **可以补充细节**：原文没说的场景细节/角色心理，可以合理补充
2. **可以推进剧情**：在已有设定框架内推进剧情
3. **可以回收伏笔**：原文埋了的伏笔，续写中可以回收
4. **可以引入新角色**：但新角色不能喧宾夺主，不能改变已有角色关系
5. **可以升级能力**：但必须符合原文的力量体系和升级逻辑

### 3.3 信息不足时怎么办
如果用户只提供了少量内容，很多信息无法确定：
- 明确标注"基于已有信息推断，可能与原作设定有出入"
- 不要编造原作没有的设定
- 可以问用户补充信息，但不要一次问太多（最多3个关键问题）

---

## 四、续写质量自检

- [ ] 读取了所有已有内容？
- [ ] 提取了世界观/人物/状态/文风/伏笔？
- [ ] 人物表基于已有内容，不是自己设计的？
- [ ] 文风匹配检查通过？
- [ ] 续写承接了上一章结尾？
- [ ] 没有改已有设定/角色/剧情？
- [ ] 回收了应该回收的伏笔？
- [ ] 八维审查通过？
- [ ] 文风一致性检查通过？
