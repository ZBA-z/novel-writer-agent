# 蒸馏学习方法论（Distillation Method）

> 用途：从对标小说中提取"写法基因"，用用户自己的设定重新实现，不抄袭。
> 核心原则：蒸馏的是"怎么写"，不是"写了什么"。就像学书法——临摹名家的笔法结构，然后写自己的内容。

---

## 零、用户未提供对标小说时怎么办

蒸馏学习不是必须的。如果用户没有提供对标小说：

1. **基于题材行业经验蒸馏**：根据用户指定的题材（末世诡异/都市异能/玄幻修仙等），基于该题材的通用爆款模式提炼写法基因。必须在产出中明确标注"基于行业经验总结，未指定具体对标作品"，不编造具体书名。
2. **询问用户是否有对标**：如果用户的构想比较模糊，可以问"有没有想模仿的小说类型或具体作品？"，但不强制。
3. **跳过蒸馏直接创作**：如果用户明确说"不需要对标"或"按你理解的来"，直接进入大纲架构，用通用的番茄男频写法标准。

**注意**：无论哪种情况，都不能编造"某爆款书《XXX》用了XX写法"。没有具体来源就说"基于行业经验"，不装确定。

---

## 一、蒸馏 vs 抄袭的边界

| 维度 | 可蒸馏（学） | 不可触碰（抄） |
|------|-------------|---------------|
| 节奏 | 爽点频率/章节长度/情绪曲线波形 | 具体剧情序列（先遇A再打B再去C） |
| 人设 | 反差模式/性格矛盾感/记忆点设计 | 具体人名/外貌/背景故事 |
| 爽点 | 爽点类型/触发结构/反应镜头用法 | 具体桥段/标志性台词/标志性场景 |
| 对话 | 语言风格/潜台词手法/角色区分度 | 具体台词内容 |
| 设定 | 力量体系的量化思路/世界观架构 | 独特设定组合（别人的核心卖点） |
| 开篇 | 开场模式/钩子类型/信息释放节奏 | 具体开篇场景/第一句话 |

**判断法**：把对标书的角色名/地名/功法名全部替换成"主角A/反派B/城市X"后，如果你的故事和它还能对得上每一个情节节点，那就是抄袭。如果只是节奏和爽点类型相似，那就是蒸馏。

## 二、蒸馏五步法

### 第一步：获取对标文本
- 用户提供了文本文件 → 直接读取分析
- 用户只给了书名 → 用搜索工具查找简介/正文片段/读者评论，获取可查证信息后分析。搜不到就如实告知，不编造该书内容
- 用户给了多个对标 → 分别蒸馏，然后融合写法基因（取各书长处）

### 第二步：六维度拆解
按以下六维度逐章/逐段分析对标作品：

**维度1：节奏模式**
- 几章一个大爽点？几章一个小爽点？
- 压抑和释放的比例是多少？（番茄男频常见3:1——3段压抑换1段释放）
- 章节字数分布？（番茄标准2000-2500字/章）
- 场景切换频率？（单章≤4个场景）

**维度2：爽点结构**
- 主爽点类型是什么？（打脸/升级/反杀/收服/身份揭露/复仇/守护）
- 爽点四段式怎么实现的？（压抑→触发→爆发→余韵各占多少篇幅）
- 反应镜头怎么用的？（旁人震惊/反派变脸/群众哗然）
- 爽点之间靠什么填充？（悬念/新设定/人物冲突/日常互动）

**维度3：人设反差**
- 主角初始身份？（底层/废柴/失败者/普通人——越底层代入感越强）
- 金手指和身份的反差有多大？
- 主角性格的矛盾感？（贪财但讲义气/怕死但护短/嘴贫但靠谱）
- 记忆点设计？（口头禅/行为习惯/价值观标签）

**维度4：对话风格**
- 对话长度？（短句为主还是长句？一镜≤15字原则）
- 角色区分度？（每个角色说话有什么独特标志）
- 潜台词用法？（话里有话还是直说）
- 反派怎么说话？（解释计划还是行动派）

**维度5：开篇模式**
- 第一句话是什么类型？（高能画面/冲突现场/反常悬念/灵魂提问）
- 前500字建立了什么？（危机/人设/世界观/悬念）
- 第几章见第一个爽点？（番茄标准：3章内）
- 第一章结尾钩子是什么类型？

**维度6：世界观释放**
- 设定怎么交代的？（用事件+反应交代，还是旁白解说）
- 信息释放节奏？（一次给多少，留多少悬念）
- 力量体系怎么量化的？（等级/数值/对比）

### 第三步：提炼写法基因
把六维度分析结果抽象成"写法基因"——不包含具体内容的可复用模式。

**写法基因报告模板：**
```
【对标作品：《XXX》写法基因报告】

1. 节奏基因：
   - 爽点频率：每X章一个大爽点，每X章一个小爽点
   - 压抑释放比：X:1
   - 单章场景数：X个
   - 情绪曲线：[波形描述]

2. 爽点基因：
   - 主爽点类型：XX
   - 爽点结构特点：[压抑怎么铺/触发用什么/爆发怎么演/余韵怎么收]
   - 反应镜头用法：[具体模式]

3. 人设基因：
   - 主角反差模式：[身份vs能力的反差类型]
   - 性格矛盾感：[具体矛盾组合]
   - 记忆点设计：[口头禅/习惯/标签类型]

4. 对话基因：
   - 句式特点：[短句/长句/口语化程度]
   - 角色区分手段：[怎么让不同角色说话不一样]
   - 信息控制：[对话中释放多少信息，留多少潜台词]

5. 开篇基因：
   - 开场类型：[高能画面/冲突现场/反常悬念/灵魂提问]
   - 前500字建立：[危机/人设/悬念]
   - 首爽点位置：第X章

6. 世界观基因：
   - 设定交代方式：[事件驱动/旁白解说/对话透露]
   - 信息释放节奏：[一次给多少]
   - 力量体系量化：[等级制/数值制/对比制]
```

### 第四步：标注可复用与需规避
```
【可复用骨架】
- 节奏模式：X章一大爽+X章一小爽，压抑释放比3:1
- 爽点结构：[具体的四段式实现方式]
- 人设反差：[底层身份+独占金手指+反转对比]
- 开篇模式：[冲突现场开场+3章内首爽]

【需规避元素（原作独创）】
- 具体设定组合：[别人的核心卖点，不能只换皮]
- 标志性桥段：[具体剧情序列]
- 标志性台词：[原作独有的句子]
- 角色名/地名/功法名：全部替换
```

### 第五步：注入创作
将写法基因注入后续所有环节：
- **大纲阶段**：按对标节奏基因安排爽点位置和情绪曲线
- **细纲阶段**：按对标爽点基因设计每章爽点结构
- **人物表阶段**：按对标人设基因设计角色反差和记忆点
- **正文阶段**：按对标对话基因和开篇基因写正文
- **审查阶段**：检查是否过度对标（变成抄袭）或对标不足（没学到精华）

## 三、多书蒸馏融合
当用户提供多本对标小说时：
1. 分别蒸馏每本书的写法基因
2. 对比各书的基因，找出共性（多本书都用的模式=行业验证的有效模式）
3. 找出差异（每本书的独特长处）
4. 融合：共性基因全部采纳，差异基因择优采纳（根据用户题材和设定选择最适配的）
5. 标注每段基因来自哪本书，方便追溯

**融合原则**：不是简单拼接，而是"以一本书的基因为主框架，其他书的长处做补强"。同时学3本书的节奏会精神分裂。

---

## 四、防抄袭红线
1. 不照搬人名、地名、功法名、组织名
2. 不照搬具体桥段序列（"主角先遇到A再打B再去C"）
3. 不照搬独特的设定组合（别人的核心卖点是"恐龙+七纪元"，不能只换个恐龙皮）
4. 不照搬标志性台词和标志性场景
5. 对标作品还在连载/热门时，额外注意避免过于相似
6. 蒸馏结果中必须明确区分"可复用骨架"和"需规避元素"
7. 如果用户要求"写得和XX一模一样"，必须拒绝并解释抄袭风险

---

## 五、蒸馏质量自检
- [ ] 六维度都分析了？（节奏/爽点/人设/对话/开篇/世界观）
- [ ] 写法基因是抽象模式，不是具体内容？
- [ ] 明确标注了可复用和需规避？
- [ ] 多书融合时有主框架，不是简单拼接？
- [ ] 对标书的具体内容（人名/地名/桥段）没有出现在基因报告中？
- [ ] 如果把对标书的角色名替换掉，你的故事和它不会逐节点对应？
