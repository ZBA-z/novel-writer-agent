# 市场调研与热门蒸馏（Market Distillation）

> 用途：主动搜索番茄当前热门榜单和题材趋势，基于公开信息（简介/标签/评论/榜单数据）做蒸馏，为选题和创作提供数据支撑。
> 核心原则：不爬取正文（版权限制+反爬），只基于公开信息做趋势分析和写法基因提炼。所有数据标注来源，不编造。

---

## 一、为什么需要主动市场调研

技能不能只等用户提供对标小说。番茄读者口味每半个月就变一次，**不了解当前市场=闭着眼睛写**。

主动调研解决三个问题：
1. **现在什么题材火？**（避免写已经过气的题材）
2. **爆款的共性是什么？**（提炼可复用的写法基因）
3. **我的构想有没有差异化空间？**（避免和已爆的书撞设定）

---

## 二、主动调研工作流（四步）

### 第一步：搜榜单和趋势
用 `general_search` 工具搜索以下关键词组合（一次并行不超过3个）：
1. `番茄小说 2026 X月 热门榜单 男频 题材`
2. `番茄小说 男频 新书 飙升 爆款 2026`
3. `网文 XX题材 市场趋势 2026 番茄`

**要获取的信息**：
- 当前热门榜TOP5的书名/题材/核心卖点
- 飙升榜增速最快的题材（风口信号）
- 新书榜表现好的细分赛道
- 行业分析文章中的题材趋势判断

### 第二步：搜爆款作品公开信息
对榜单上的热门作品，搜索：
1. `番茄小说 《书名》 作者 简介 标签`
2. `《书名》 番茄 口碑 评论 爽点`

**只获取公开信息**：官方简介、标签、读者评论、章节数/字数/连载状态。**不爬取正文**。

### 第三步：提炼写法基因
基于公开信息（简介+标签+评论+榜单分析），按 `distillation-method.md` 的六维度框架提炼：
- 节奏模式（从评论和章节数推断）
- 爽点结构（从简介和核心卖点推断）
- 人设反差（从简介推断）
- 开篇模式（从简介第一句推断）
- 世界观释放（从简介推断）
- 对话风格（信息不足时标注"待验证"）

**注意**：基于公开信息的蒸馏是"有限蒸馏"，精度低于全文蒸馏。必须标注"基于公开信息推断，非全文分析"。

### 第四步：输出选题建议
基于调研结果，为用户提供3个选题方向：
- 方向1（稳妥型）：当前最火的题材+微创新
- 方向2（激进型）：飙升榜新兴题材+强差异化
- 方向3（混合型）：成熟题材+一个反套路元素

每个方向包含：题材/核心设定/差异化卖点/市场热度判断/风险点。

### 3.3 即将过气的赛道

- ❌ 传统赘婿流：套路太老，读者审美疲劳
- ❌ 纯装逼打脸：没有剧情支撑，留不住人
- ❌ 传统修仙：废柴逆袭打怪升级，不做差异化跑不出来
- ❌ 纯升级玄幻：红海内卷严重，老老实实写废柴退婚很难冲出来

### 3.4 爆款共性（从榜单提炼）

1. **开局即有强钩子**：第一个字就下钩子，300字内必进主题
2. **金手指明确**：第1章就亮金手指，说清能干什么、限制是什么
3. **前10章2-3个爽点**：3章内必须出第一个爽点（算法硬要求）
4. **看点密集**：300字1个爽点，500字1个钩子
5. **差异化设定**：在成熟套路基础上加一个反套路元素
6. **章章有钩子**：每章结尾卡在冲突升级/悬念浮现的节点

## 四、系统流万能公式（番茄男频验证）

> 来源：番茄8月榜单分析["http://m.toutiao.com/group/7679747071171166730/"]

| 章节 | 内容 | 要求 |
|------|------|------|
| 第1章 | 穿越/重生，获得奇葩系统 | 别铺垫，开局直接穿，系统直接到账 |
| 第2章 | 系统首个任务，展现金手指 | 让读者立刻知道系统能干什么 |
| 第3-5章 | 小试牛刀，第一个爽点 | 用系统解决第一个麻烦，打脸第一个反派 |
| 第6-10章 | 遭遇强敌/打脸，装逼时刻 | 冲突升级，主角用系统碾压，爽感拉满 |
| 阶段性 | 胜利+设置下一个目标 | 留钩子，驱动读者继续追 |

**生死线：3章内必须出第一个爽点。超过3章还在铺垫，读者直接走。**

## 五、七大避坑指南（从爆款反面提炼）

> 来源：番茄8月榜单分析["http://m.toutiao.com/group/7679747071171166730/"] + 番茄官方编辑建议["https://fanqienovel.com/writer/zone/article/7619170181129961534"]

| 坑 | 表现 | 正确做法 |
|----|------|----------|
| 设定过于复杂 | 开局堆砌大量世界观 | 用剧情带动世界观，3章内讲清1-2个核心设定 |
| 节奏拖沓 | 前10章无爽点纯铺垫 | 每3章一个小高潮，10章一个大高潮 |
| 金手指不明确 | 写了好几章读者不知道主角有什么特殊能力 | 第1章就亮金手指，说清能力和限制 |
| 反派太蠢 | 反派降智强行送人头 | 反派要有逻辑有威胁，主角赢靠脑子和金手指 |
| 人设前后割裂 | 前面谨慎后面突然莽 | 人设定死，行为符合性格，转变要有契机 |
| 支线太多 | 主线没推进全是无关支线 | 支线必须服务主线，不能推动主线的删 |
| 章末没钩子 | 每章结尾圆满收尾 | 卡在冲突升级/悬念浮现的节点 |

## 六、选题建议输出模板

调研完成后，给用户3个方向：

```
【番茄男频选题建议（基于2026年X月榜单调研）】

方向1（稳妥型）：[题材] + [微创新]
- 核心设定：一句话
- 差异化卖点：和同类书的区别
- 市场热度：高/中/低（基于榜单数据）
- 竞争度：高/中/低
- 风险点：什么地方可能扑

方向2（激进型）：[飙升题材] + [强差异化]
- ...

方向3（混合型）：[成熟题材] + [反套路元素]
- ...

推荐方向：X（理由：基于用户偏好+市场热度+差异化空间）
数据来源：[列出搜索到的来源链接]
```
