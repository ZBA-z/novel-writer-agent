# 番茄合规专项指南（Compliance Guide）
> 用途：番茄小说平台的内容审核规则，特别是末世诡异题材的高危区域。合规红线零容忍，触碰直接限流/下架。

---

## 一、番茄通用红线（绝对不能碰）

### 1.1 政治敏感
- 不能出现真实国家领导人姓名/形象
- 不能影射政治体制/政治事件
- 不能出现真实国旗/国徽/军队番号
- 政府/公安/军队等机构不能负面描写（建议虚构化："异常管理局"代替真实机构）

### 1.2 色情低俗
- 不能有性行为详细描写
- 不能有未成年人任何性暗示
- 不能有乱伦/强奸详细描写
- 暧昧描写点到为止（拉手/拥抱/亲吻可以，再往下不行）

### 1.3 血腥暴力
- 不能有虐杀/酷刑详细过程
- 不能针对儿童/老人的暴力
- 不能有"吃人肉"等极端描写（末世题材特别注意）
- 战斗写结果不写过程细节（"对方倒下"不写"肠子流了一地"）

### 1.4 违法犯罪
- 不能有制毒/武器制作/黑客/诈骗的详细步骤
- 不能有自杀方法的详细描写
- 不能有毒品/赌博的正面描写
- 反派的犯罪行为可以写，但不能写成教程

### 1.5 宗教民族
- 不能贬低真实宗教
- 不能有民族歧视
- 邪教不能正面描写（邪教必须是反派，最终被正义战胜）

## 二、末世诡异题材特别高危区

### 2.1 "吃人"描写
**高危**：末世题材容易出现"人吃人"的情节。
**安全写法**：
- 可以暗示"有人失踪""食物短缺"，但不要直接写吃人
- 如果必须写，用"传闻""有人说"等间接方式，不详细描写
- 绝对不能写主角吃人（会被读者骂+审核风险）

### 2.2 血腥描写
**高危**：诡异/怪物战斗容易写得太血腥。
**安全写法**：
- 用"暗红色液体"代替"血"
- 用"倒下的身影"代替"尸体"
- 用"物体断裂"代替"砍/劈/斩"
- 战斗写结果（"对方不再动弹"），不写过程细节（"鲜血飞溅"）
- 怪物的"血"可以是黑色/绿色液体，不是人类的血

### 2.3 恐怖/诡异描写
**高危**：诡异题材的恐怖元素可能触发审核。
**安全写法**：
- 用氛围/暗示/角色反应写恐怖，不直接描写恐怖画面
- "黑暗中有东西在动"比"一只腐烂的手伸出来"更安全也更高级
- 不可名状的诡异用抽象描写（"光线被吞噬""空间扭曲"），不具体描写怪物外形
- 局部特写+剪影+虚化，不全景展示怪物

### 2.4 邪教/仪式描写
**高危**：归一会/邪教献祭等情节。
**安全写法**：
- 邪教必须是反派，最终被正义战胜
- 仪式描写点到为止，不详细描写献祭过程
- 不能出现真实宗教符号/仪式
- 用虚构的符号/组织名

### 2.5 自杀/绝望描写
**高危**：末世题材容易出现角色绝望自杀。
**安全写法**：
- 可以写角色绝望，但不能详细描写自杀方法
- 主角不能自杀（正能量要求）
- 配角自杀可以作为剧情，但不能美化/鼓励
- 最终结局必须是希望/抗争，不是全员死亡

### 2.6 真实地名+负面事件
**高危**：用真实城市名+灾难事件。
**安全写法**：
- 城市名虚构化（"江城""临市"代替真实城市名）
- 不影射真实灾难事件
- 政府/军队的反应要正面（积极救援/保护民众），不能写政府无能

## 三、敏感词替换表

| 高危词 | 替换为 |
|--------|--------|
| 血/流血 | 暗红色液体/身体上的暗色痕迹 |
| 尸体/死尸 | 倒下的身影/静止的轮廓 |
| 杀/杀死 | 击败/倒下/不再动弹 |
| 砍/劈/斩 | 刀刃划过/物体断裂 |
| 炸/爆炸 | 强光爆发/冲击波扩散 |
| 枪/开枪 | 火光闪过/物体上出现焦痕 |
| 政府/公安 | 管理局/特勤组（虚构机构） |
| 具体国家名 | 虚构国名/"联盟" |

## 四、合规自检清单（每章必查）

- [ ] 无政治敏感内容？
- [ ] 无色情低俗/未成年人暗示？
- [ ] 无血腥过度（虐杀/酷刑/针对儿童老人）？
- [ ] 无违法犯罪教程（制毒/武器/黑客/诈骗步骤）？
- 无宗教民族问题？
- [ ] 末世题材：无"吃人"详细描写？
- [ ] 末世题材：血腥用了安全替换词？
- [ ] 末世题材：恐怖用氛围暗示而非直接描写？
- [ ] 末世题材：邪教是反派且最终被战胜？
- [ ] 末世题材：无真实地名+负面事件？
- [ ] 敏感词已替换？
- [ ] 结局是正能量（抗争/希望/守护）？

## 五、被审核拒了怎么办
1. **不要硬刚**：审核是机器+人工，拒了就改
2. **定位问题**：看审核提示的违规类型，定位到具体段落
3. **替换修改**：用安全替换词，或删除/改写违规段落
4. **重新提交**：修改后重新提交审核
5. **记录问题**：把被拒的原因记录下来，后续避免
