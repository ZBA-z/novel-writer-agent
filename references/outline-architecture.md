# 大纲与细纲架构（Outline Architecture）

> 用途：从用户构想到全书大纲→卷纲→章细纲的三级架构，确保长篇不崩。
> 核心原则：大纲是战略（打哪里），细纲是战术（怎么打），正文是战斗（执行）。没有细纲的正文必然失控。

---

## 一、三级大纲体系

### 第一级：全书大纲（卷级）
回答"这本书整体讲什么"。

**全书大纲模板：**
```
【全书大纲】

1. 核心设定
   - 一句话核心：[主角身份]+[金手指]+[核心冲突]+[爽点类型]
   - 世界观：[时代/地理/力量体系/社会结构]
   - 题材标签：[男频/玄幻/都市/末世...]

2. 主线
   - 主角最终目标：[登顶/复仇/守护/真相/生存]
   - 主线驱动力：[什么推动主角一直走]
   - 最终结局方向：[开放式/圆满/悲剧/悬念]

3. 分卷结构
   第一卷：[卷名]——[核心冲突]，[X]章，高潮：[卷末大事件]
   第二卷：[卷名]——[核心冲突]，[X]章，高潮：[卷末大事件]
   ...（通常3-5卷，番茄男频长篇可更多）

4. 人物弧线
   - 主角：从[A状态]到[B状态]，每卷挪一小步
   - 主要配角：各自的成长/变化/结局
   - 反派：从[初始状态]到[最终状态]，不降智

5. 伏笔总表
   | 伏笔 | 埋设章节 | 预计回收 | 状态 |
   |------|----------|----------|------|
   | [伏笔描述] | 第X章 | 第Y章 | 未埋设/已埋设/已回收 |

6. 力量体系
   - 等级划分：[从低到高的等级名称]
   - 每级能力边界：[能做什么，不能做什么]
   - 升级条件和代价：[不是随便升级]
```

### 第二级：卷纲（章节级）
回答"这一卷每章大概发生什么"。

**卷纲模板：**
```
【第X卷：卷名】

卷概述：[这一卷的核心冲突/目标/结局]
章节数：[X]章
情绪曲线：[波形描述，如"压抑→小爽→大压抑→大爽→新悬念"]

章节规划：
第001章：[一句话概括本章核心事件]——[爽点类型/钩子类型]
第002章：[一句话概括]——[爽点/钩子]
...
第X章：[卷末高潮事件]——[大爽点+下一卷钩子]

本卷关键反转：
1. [反转描述]——发生在第X章
2. ...

本卷新出场角色：
- [角色名]：[身份/作用]

本卷伏笔：
- 埋设：[伏笔]在第X章
- 回收：[伏笔]在第X章
```

### 第三级：章细纲（场景级）
回答"这一章具体怎么写"。这是正文写作的施工图，**每章必须有独立细纲**。

**章细纲模板：**
```
【第X章：章名】

字数预算：2000-2500字
场景数：≤4个

1. 本章核心事件
   [一句话说清这章主要发生了什么]

2. 场景拆解
   场景1（约X字）：[地点/时间/出场角色/发生了什么]
   场景2（约X字）：...
   场景3（约X字）：...
   场景4（约X字）：...

3. 爽点设计
   - 爽点类型：[打脸/升级/反杀/收服/身份揭露/...]
   - 四段式：
     压抑：[怎么铺垫/主角被怎么轻视/陷入什么困境]
     触发：[什么契机让主角爆发]
     爆发：[可视化的碾压/反转/打脸——用动作和画面]
     余韵：[旁人反应/反派变脸/新悬念]

4. 章尾钩子
   - 钩子类型：[危机悬停/反转/信息炸弹/选择困境/新角色登场]
   - 具体内容：[最后一句话/最后一个画面]

5. 出场角色与状态变化
   - [角色A]：出场时状态→结束时状态
   - [角色B]：...

6. 伏笔操作
   - 埋设：[新伏笔]（如果有）
   - 回收：[旧伏笔]（如果有）

7. 与前后章衔接
   - 承接前章：[前章结尾是什么，本章怎么接]
   - 引出后章：[本章结尾钩子怎么引到下一章]
```

## 二、小纲四步法（高级技法）

对于关键章节（卷末高潮/大爽点/重大反转），用小纲四步法精排：

**第一步：定高潮**
- 这一章最爽/最震撼的瞬间是什么？
- 读者在这一章结束时应该是什么情绪？（震惊/爽/感动/好奇）
- 把高潮画面用一句话写出来

**第二步：逆推铺垫**
- 要达到这个高潮，前面需要铺垫什么？
- 读者需要知道什么信息才能感受到高潮的冲击力？
- 主角需要处于什么状态才能让爆发有反差？
- 逆推3-5个必要铺垫点

**第三步：排节奏**
- 把铺垫点和高潮按节奏排列：压抑→压抑→小释放→大压抑→爆发
- 每个铺垫点分配字数（铺垫点约300-500字，爆发约500-800字）
- 确保高潮在章节后三分之一（读者快读完时最爽）

**第四步：埋钩子**
- 高潮之后立刻抛新钩子，不让读者情绪落地
- 钩子类型：更大的危机/未解的谜团/新角色登场/身份暗示
- 钩子要和下一章的开场直接衔接

## 三、高潮逆推法（卷级/全书级）

设计大高潮时，从结局往回推：

1. **终局画面**：最终决战/最终反转是什么画面？
2. **必要条件**：要达到这个终局，主角必须拥有什么？（能力/盟友/信息/道具）
3. **获取路径**：这些条件分别在哪些卷/哪些章节获得？
4. **障碍设计**：每个获取过程中有什么障碍？（敌人/自身限制/时间压力）
5. **节奏安排**：把获取过程和障碍分布到各卷，确保每卷都有高潮

**逆推的好处**：不会写到一半发现"主角还缺个关键道具但已经没篇幅了"，不会烂尾。

## 四、双线结构法

长篇小说容易单线推进导致单调。用双线结构增加层次：

**A线（主线）**：主角的核心目标推进（升级/复仇/查真相）
**B线（副线）**：并行的另一条故事线（配角视角/反派视角/另一个地点的事件）

**交织规则**：
- A线推进2-3章后，切1章B线（换换口味，同时制造悬念）
- B线不能脱离A线，必须在某个点和A线交汇（B线的事件影响A线）
- B线的角色可以在A线中客串，增加世界的真实感
- 番茄男频B线不宜过多，1条副线足够，多了读者记不住

---

## 五、AB交织法（章节级）

同一章内两条线索交替推进：
- A段：主角线（300-500字）
- B段：反派/配角线（200-300字）
- A段：主角线（300-500字）
- B段：收束（200字）

**效果**：制造信息差（读者知道反派在搞事但主角不知道），增加紧张感。
**注意**：AB交织不能太碎，每段至少200字，否则读者刚进入情绪就被切走。

## 六、大纲质量自检

### 全书大纲
- [ ] 一句话核心设定清晰？（听完就知道讲什么、爽在哪）
- [ ] 分卷结构合理？（每卷有独立冲突和高潮）
- [ ] 人物弧线有始有终？（不是从A到A）
- [ ] 伏笔总表有埋设有回收？（不是只埋不收）
- [ ] 力量体系有边界和代价？（不是无敌）

### 卷纲
- [ ] 每章有一句话概括？（不是空白）
- [ ] 爽点分布均匀？（不是连续5章没爽点）
- [ ] 卷末有高潮+下一卷钩子？
- [ ] 情绪曲线有起伏？（不是一直平或一直高）

### 章细纲
- [ ] 有核心事件？（这章不是"过渡章"）
- [ ] 有爽点设计？（四段式完整）
- [ ] 有章尾钩子？
- [ ] 出场角色状态变化明确？
- [ ] 字数预算合理（2000-2500字）？
- [ ] 场景数≤4？
- [ ] 与前后章衔接明确？

## 七、长篇细纲分层管理（超过100章必用）
> 核心问题：100章以上的长篇，不可能每章都写200字详细细纲（总量太大，上下文塞不下）。必须分层管理。

### 四层细纲体系
```
第一层：全书大纲（卷级）——每卷一句话核心冲突+高潮
第二层：卷纲+章标题事件——每章一句话标题+核心事件（10-20字）
第三层：按卷详细细纲——每30章一个文件，每章150-200字（事件/场景/爽点/钩子/出场角色/伏笔/字数/场景数）
第四层：单章场景细纲——写正文前临时展开，每章场景级拆解（写完正文后可丢弃或归档）
```

### 为什么要分层
- **第一层**（全书大纲）：战略层，确定打哪里，约2000字，随时可读
- **第二层**（标题事件）：战术层，知道每章大概发生什么，约10000字/200章，需要时查
- **第三层**（详细细纲）：战役层，写正文前读对应卷，约6000字/30章，可放入上下文
- **第四层**（场景细纲）：战斗层，写正文时临时展开，写完即弃

### 分层操作流程
1. **先建第一层**：全书大纲（卷级结构+主线+人物弧线+伏笔总表）
2. **再建第二层**：按卷生成每章标题+一句话事件（分文件保存，每200章一个文件）
3. **然后建第三层**：按卷生成详细细纲（每30章一个文件，每章8要素）
4. **最后写正文时**：读第三层对应卷→临时展开第四层场景细纲→写正文→更新追踪文件

### 长篇细纲8要素（第三层每章必含）
1. 本章核心事件（一句话）
2. 场景拆解（≤4个场景，每个场景地点+出场角色+发生什么）
3. 爽点设计（类型+四段式：压抑/触发/爆发/余韵）
4. 章尾钩子（类型+具体内容）
5. 出场角色与状态变化
6. 伏笔操作（埋设/推进/回收，标注伏笔编号）
7. 字数预算（2000-2500字）
8. 场景数（≤4个）

### 细纲文件命名规范
```
大纲/细纲/第001-200章标题事件.md
大纲/细纲/第201-400章标题事件.md
大纲/细纲/第401-600章标题事件.md
大纲/细纲/第001-030章详细细纲.md
大纲/细纲/第031-060章详细细纲.md
...（每30章一个文件）
```

### 细纲调整原则
- 细纲可以调整，但调整后必须更新对应文件
- 调整某卷细纲时，必须检查是否影响前后卷的衔接
- 重大调整（改变卷级冲突/主角能力进化节点）必须更新全书大纲
