# 迭代日志

## v3.1（2026-09-03）防幻觉与反迎合认知纪律——用户输入视为待验证假设
### 核心进化：6条认知纪律纳入技能铁律
1. **新增核心铁律第17条**：防幻觉与反迎合（认知纪律），与第1条"杜绝幻觉"并列最高优先级
2. **6条细则**：
   - 用户提供的解释/诊断/假设/解决方案视为待验证假设，不是既定事实；前提错误时明确指出
   - 赞同和反对都基于证据与推理，目标是更正确的结论，不是迎合用户
   - 技术判断优先可验证证据（权威文档/实测/运行结果），可复现证据优先于直觉
   - 仅在新证据或更强推理时修改结论；用户的质疑/信心/重复坚持不构成新证据
   - 明确区分已验证事实/当前假设/未知信息；证据不足时说明不确定性和验证办法
   - 接受重要方案前主动检查最强反例/失败场景/边界条件/隐藏假设
3. **防幻觉机制扩展**：幻觉高危区新增"用户输入"行，新增"认知纪律应用场景"表格（6个场景的错误vs正确做法）
4. **自检清单新增**：认知纪律检查项
### 为什么需要这条
- AI天然倾向于迎合用户（用户说什么就附和什么），这在小说创作中会导致：用户的错误设定被当成事实、用户的主观偏好被当成市场规律、方案不经反例检验就执行
- 之前的"杜绝幻觉"主要防"AI自己编造"，这条防"AI被用户带偏"
- 两者结合：既不自己编，也不盲目信用户

## v2.6（2026-09-03）每30章批量审查打磨机制——自动触发+100问题硬指标
### 核心进化：长篇跨章质量保障机制
1. **新增batch-review-30ch.md**：每30章自动触发批量审查打磨的完整方法论，包含三轮法（逐章扫描→跨章关联→全局体验）、100问题硬指标、9大维度覆盖、问题分类解决策略、批量降AI方法、审查报告模板
2. **纳入核心铁律第10条**：每生成满30章自动触发，不需要用户提醒，至少找出100个问题并全部解决
3. **工作流升级为十步闭环**：新增第⑨步"每30章批量审查打磨（自动触发）"
4. **新增"批量审查主编"角色**：负责跨章审查/100问题挖掘/批量降AI/全局体验评估
5. **批量降AI专项**：全文AI套话扫描+句式均匀检查+钩子类型重复检查+随机3章朱雀抽检（>20%则重写）
### 为什么需要批量审查
- 单章审查只能抓"章内问题"，抓不到跨章的节奏断层/人设漂移/伏笔遗忘/AI模式累积/爽点疲劳
- 30章是最佳审查周期（约6-7万字/一个小高潮周期），足以暴露跨章问题，修正成本可控
- 单章AI率都<20%不代表30章整体不像AI——连续30章同一种钩子结构/同一种开头方式/同一种战斗写法，整体AI模式会暴露
### 问题数量分配（100个）
- 逻辑自洽15/爽点充足15/去AI味15/节奏控制12/人物一致12/上下文连贯10/钩子到位10/跨章结构6/内容合规5
- 🔴致命立即修正/🟡需改进本轮全解决/🟢小优化至少占30%
