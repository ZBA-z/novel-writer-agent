# 黄金三章专项（Opening Three Chapters）

> 用途：番茄男频前三章定生死。前3章数据不好，后面写得再好也难拿到推荐。本文件提供前三章的精确写作标准和模板。
> 核心数据来源：番茄官方编辑课程["https://fanqienovel.com/writer/zone/article/7619170181129961534"]、番茄8月榜单分析["http://m.toutiao.com/group/7679747071171166730/"]、番茄新人算法生存法则["https://post.m.smzdm.com/p/aqrpl66k/"]

---

## 一、为什么前三章是生死线

番茄算法逻辑：
- 前3章决定**首章留存率**和**追读率**
- 首章留存率低于30%的书难以获得推荐（行业经验判断，非官方公开数据）
- 3章内不出第一个爽点，读者直接弃书
- 平台算法偏好"强情绪、快节奏、低门槛"内容

**前三章必须完成的三件事**：
1. 确立核心困境（主角面临什么危机/矛盾）
2. 亮金手指/转折（主角获得什么改变命运的优势）
3. 第一个小高潮+留悬念（主角用金手指完成第一次成功，钩住读者）

## 二、黄金三秒开篇（第一章前300字）

> 番茄官方标准：第一个字开始下钩子，三段话内必有重点，300字内必进主题。

### 2.1 开篇四铁律
1. **第一句50字内**，出现反常/冲突/秘密
2. **涉及生死/金钱/重大秘密**（高情绪锚点）
3. **主角在主动行动**（不是被动等待/旁白介绍）
4. **300字内进入主题**（不写背景/天气/世界观介绍）

### 2.2 开篇第一句模板（验证有效）

| 类型 | 模板 | 示例 |
|------|------|------|
| 数字反差 | "测灵石上限100，我测出0。" | 0是"道生一"之前的状态 |
| 反常悬念 | "我死后的第三天，自己推开了家门。" | 死亡+复活的矛盾 |
| 冲突现场 | "刀架在脖子上，我笑了。" | 生死危机+反常反应 |
| 判决式 | "你有罪。""凭什么？" | 直接进入冲突 |
| 身份反差 | "全宗门都以为我是废柴，只有我知道，我已经活了三千年。" | 信息差钩子 |
| 系统激活 | "【叮。检测到宿主濒死。献祭系统激活。】" | 直接亮金手指 |

### 2.3 开篇绝对不能做的事
- ❌ 天气描写开场（"天空阴沉沉的，仿佛预示着什么"）
- ❌ 世界观介绍（"2045年，红月降临，百分之九十的人变成怪物"）
- ❌ 主角起床/走路/吃饭等日常流水
- ❌ 大段旁白/前情提要
- ❌ 主角为了救不相干的人陷入险境（圣母情节，立刻流失读者）

## 三、第一章：钩子+金手指+困境

### 3.1 第一章结构（2000-2500字）

```
[0-300字] 黄金三秒：反常/冲突/秘密开场，主角在行动中
[300-800字] 建立困境：主角面临什么危机/被轻视/绝境
[800-1200字] 金手指激活：系统觉醒/能力发现/身世揭秘
[1200-1800字] 第一次使用：主角用金手指解决眼前小麻烦
[1800-2200字] 小爽点：打脸/脱困/获益，旁人反应
[2200-2500字] 章尾钩子：更大的危机/新角色/真相碎片
```

### 3.2 第一章必须包含的要素
- [ ] 第一句50字内有钩子
- [ ] 300字内进入主题
- [ ] 主角的核心困境明确（穷/弱/被欺/绝境）
- [ ] 金手指在本章内激活（不拖到第二章）
- [ ] 金手指的能力和限制说清（读者知道能干什么）
- [ ] 至少1个小爽点（用金手指解决一个麻烦）
- [ ] 章尾有钩子（不圆满收尾）
- [ ] 300字1个爽点/趣味点，500字1个小钩子

### 3.3 第一章正反例

**❌ 反面教材**：
> 2045年，红月降临，全球百分之九十的人口变成了诡异生物。林默是一个普通的外卖员，每天在废墟中穿梭送餐。这天他像往常一样出门，天空阴沉沉的……
（问题：世界观播报+日常流水+没有钩子+300字还没进主题）

**✅ 正面教材**：
> 触手缠上脖子的那一刻，林默想的是：早上那半块饼干还没吃完。
> 【叮。检测到宿主濒死。献祭系统激活。】
> 他低头看了看缠在脖子上的黑色触手，又看了看眼前弹出的半透明面板。
> "献祭诡异，获得神力点？"林默咳了口血，"这波不亏。"
（问题：第一句就是生死危机+反常心理+系统激活+人设标签，300字内全部到位）

## 四、第二章：展现金手指+小冲突

### 4.1 第二章结构
```
[章首] 承接第一章钩子，快速回应（不拖）
[前段] 金手指的具体功能展示（让读者知道怎么用）
[中段] 新的小冲突/麻烦出现（比第一章的麻烦升级）
[后段] 主角用金手指解决冲突，获得成长/资源
[章尾] 新钩子：更大的威胁/新角色登场/真相碎片
```

### 4.2 第二章要点
- 章首5秒内回应上一章的钩子（不要拖）
- 展示金手指的具体用法（不是只说"系统很厉害"）
- 冲突比第一章升级（第一章是小麻烦，第二章是更大的麻烦）
- 主角获得实际成长（神力点/新技能/新信息）
- 引入至少一个新角色或新势力（扩展世界）
- 章尾钩子比第一章更大

---

## 五、第三章：第一个爽点爆发+确立目标

### 5.1 第三章结构
```
[章首] 承接第二章钩子
[前段] 矛盾激化：反派/危机全面爆发
[中段] 主角用金手指+智慧解决危机（第一个大爽点）
[后段] 爽点余韵：旁人震惊/反派变脸/主角获益
[章尾] 确立长期目标+更大钩子（驱动读者追更）
```

### 5.2 第三章是生死线
**3章内必须出第一个完整爽点（压抑→触发→爆发→余韵）。**
- 这是平台算法的硬要求
- 前3章数据不好，后面写得再好也难拿到推荐
- 爽点必须是"完整四段式"，不是"主角变强了"一句话带过

### 5.3 第三章后必须确立的东西
- 主角的短期目标（接下来要干什么）
- 主角的长期目标（最终要达成什么）
- 主要反派/威胁的轮廓（读者知道敌人是谁）
- 世界观的核心规则（1-2条，不用全讲）
- 追更动力（下一章会发生什么让人期待的事）

## 六、前三章节奏检查清单

写完前三章后，逐项检查：

### 节奏密度
- [ ] 每章300字内有1个爽点/趣味点？
- [ ] 每章500字内有1个小钩子？
- [ ] 每章末尾有卡点+悬念？
- [ ] 3章内出了第一个完整爽点（四段式）？

### 信息释放
- [ ] 第1章亮了金手指？
- [ ] 3章内讲清了1-2个核心设定？
- [ ] 没有堆砌世界观？
- [ ] 背景信息穿插在对话/行动中，不是旁白播报？

### 人物
- [ ] 主角的困境让读者共情？
- [ ] 主角有辨识度（口头禅/习惯/价值观）？
- [ ] 至少1个配角有记忆点？
- [ ] 反派有逻辑，不是降智送人头？

### 开篇
- [ ] 第一句50字内有钩子？
- [ ] 300字内进入主题？
- [ ] 没有天气/世界观/日常开场？
- [ ] 主角在主动行动，不是被动等待？

### 避坑
- [ ] 没有圣母情节（救不相干的人陷入险境）？
- [ ] 没有反派复读机（同一句话反复说）？
- [ ] 没有隐忍超过3章（受委屈到打脸不超过3章）？
- [ ] 支线没有偏离主线？

## 八、前三章数据自查（模拟算法视角）

写完后，模拟番茄算法的判断：

1. **首章留存率预测**：读者看完第一章会点第二章吗？
   - 如果第一章前300字没有钩子→留存率低
   - 如果第一章没有爽点→留存率低
   - 如果第一章章尾没有钩子→留存率低

2. **追读率预测**：读者看完前三章会继续追吗？
   - 如果3章内没有完整爽点→追读率低
   - 如果主角目标不明确→追读率低
   - 如果世界观太复杂看不懂→追读率低

3. **推荐池预测**：算法会给推荐吗？
   - 强情绪（仇恨/爽感/好奇）→推荐
   - 快节奏（无拖沓）→推荐
   - 低门槛（容易看懂）→推荐
   - 三项都满足→大概率进推荐池
