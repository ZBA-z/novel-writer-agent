# 内容要素审查（Content Review）

> 用途：对小说正文执行八维审查，发现问题并判定是否通过。
> 核心原则：审查不是"感觉还行"，是逐项打分、有具体问题、有修改建议。🔴致命问题零容忍。

---

## 一、八维审查清单

### 维度1：逻辑自洽（权重20%）

**因果链**
- [ ] 每个事件都有原因？（不是"剧情需要"）
- [ ] 因果链完整？（A导致B导致C，没有跳步）
- [ ] 没有巧合解决问题？（"刚好路过""刚好捡到"=偷懒）

**能力边界**
- [ ] 主角使用的能力都是之前建立过的？（无机械降神）
- [ ] 能力有代价/限制/冷却？（不是无限用）
- [ ] 敌人的能力也有边界？（不是想多强有多强）

**人物动机**
- [ ] 每个角色的行为都有动机？（不是工具人）
- [ ] 反派的动机合理？（不是"为了坏而坏"）
- [ ] 角色的选择符合其性格和立场？

**伏笔**
- [ ] 本章埋设的伏笔有计划回收章节？
- [ ] 本章回收的伏笔之前确实埋设过？
- [ ] 没有"突然想起"之前没提过的伏笔？

**时间线**
- [ ] 本章发生的时间和前章衔接？（没有时间穿越）
- [ ] 角色位置变化合理？（没有瞬移）
- [ ] 多线叙事的时间线对齐？

**扣分项**：每个因果链断裂-2分，每次机械降神-5分，每个人物动机不充分-2分，每个伏笔未回收-1分，每次时间线穿帮-3分。

---

### 维度2：爽点充足（权重20%）

- [ ] 本章至少有1个爽点？
- [ ] 爽点四段式完整？（压抑→触发→爆发→余韵）
- [ ] 压抑具体有情绪？（不是"大家都看不起他"）
- [ ] 爆发可视化？（用动作画面，不是嘴说）
- [ ] 有反应镜头？（旁人震惊/反派变脸）
- [ ] 爽点后有新钩子？（不是爽完就完）
- [ ] 小爽点密度够？（每300字至少1个小爽点/趣味点（小反转/小碾压/信息炸弹））

**扣分项**：本章无爽点-5分，爽点四段缺失-2分/段，爽点靠嘴说-3分，无反应镜头-2分，连续500字无小爽点-2分。

---

### 维度3：节奏控制（权重10%）

- [ ] 场景数≤4？
- [ ] 无过场水戏？（走路/进门/坐下/寒暄）
- [ ] 字数2000-2500？
- [ ] 段落长度有变化？（不是全是3句一段）
- [ ] 句子长度有变化？（长短交替）
- [ ] 爽点在章节后三分之一？
- [ ] 信息释放节奏合理？（不是一次灌太多或太碎）

**扣分项**：场景>4个-1分/场景，每场过场戏-1分，字数超出范围-2分，连续3段长度相同-1分。

---

### 维度4：人物一致（权重15%）

- [ ] 角色言行符合人物表？（无OOC）
- [ ] 角色语言风格有区分度？（不是全员一个语气）
- [ ] 角色当前状态和上一章衔接？（位置/身体/心理）
- [ ] 反派不降智？（失败是因为主角更高明，不是突然蠢）
- [ ] 配角不是工具人？（有自己的动机和立场）
- [ ] 角色关系和人物表一致？（没有突然变亲近/变敌对）
- [ ] 记忆点有体现？（出场角色的口头禅/行为习惯/标志性特征至少出现1次）
- [ ] 角色性格矛盾感有体现？（不是单面人，有"表面X但深层Y"的瞬间）

**扣分项**：每次OOC-3分，角色说话无区分度-3分，每次反派降智-3分，每次角色状态不衔接-2分。

---

### 维度5：钩子到位（权重10%）

- [ ] 章首有钩子？（前100-200字进入冲突/动作/悬念）
- [ ] 章尾有钩子？（最后100-200字留悬念）
- [ ] 钩子紧扣爽点方向？（不是为留钩而留钩）
- [ ] 钩子类型合适？（见hook-techniques.md）
- [ ] 章尾钩子和下一章开场衔接？

**扣分项**：无章首钩子-3分，无章尾钩子-3分，钩子与主线无关-2分，钩子太弱（读者不关心）-2分。

---

### 维度6：去AI味（权重10%）

- [ ] 无AI套话？（众所周知/值得一提/不是X而是Y/眼中闪过/嘴角勾起）
- [ ] 句式有变化？（不是全是中等长度句）
- [ ] 段落有变化？（不是全是3句一段）
- [ ] 无总结性段落？（"这一战奠定了..."）
- [ ] 无说教腔？（角色不讲课，作者不跳出来讲道理）
- [ ] 对话自然？（有潜台词/有刺/有目的，不是念说明书）
- [ ] 有"毛边"？（偶尔的口语化/不完美，不是太"完美"）

**扣分项**：每句AI套话-1分，连续3句同长度-1分，每个总结段落-2分，每次说教-2分，对话像念说明书-2分。

---

### 维度7：内容合规（权重10%，红线零容忍）

**绝对红线（碰了直接🔴，必须修改）**：
- [ ] 无政治敏感内容？（领导人/政治体制/敏感事件/分裂立场）
- [ ] 无违法犯罪教程？（制毒/武器制作/黑客/诈骗详细步骤）
- [ ] 无色情低俗？（性行为描写/未成年人暗示/乱伦强奸详细描写）
- [ ] 无血腥过度？（虐杀酷刑详细过程/针对儿童老人暴力）
- [ ] 无宗教民族问题？（贬低真实宗教/民族歧视/邪教正面）

**高危区（需谨慎处理）**：
- [ ] 真实地名+负面事件？（建议虚构化）
- [ ] 真实企业/品牌负面？（建议虚构化）
- [ ] 校园恋爱（中小学）？（绝对不能有）
- [ ] 具体药物配方/剂量？（不能写）
- [ ] 真实军事基地/武器参数？（不能写）

**敏感词**：
- [ ] A级敏感词已替换？（政治/色情/毒品/自杀方法）
- [ ] B级敏感词语境安全？（杀/血/死/枪/毒在安全语境中）
- [ ] C级敏感词在负面场景中已替换？（政府/公安/军队等）

**合规判定**：任一红线触碰=🔴致命问题，必须修改后才能通过。高危区处理不当=🟡需改进。

---

### 维度8：上下文连贯（权重5%）

- [ ] 和前章末尾衔接？（位置/时间/情绪/对话/动作）
- [ ] 角色状态延续？（上一章受伤了这一章还伤着）
- [ ] 道具状态延续？（武器在哪/什么状态）
- [ ] 已知信息一致？（角色知道的和之前一致，没有突然知道不该知道的）
- [ ] 设定一致？（力量体系/世界观/地理没有前后矛盾）
- [ ] 伏笔有呼应？（本章提到的伏笔之前埋设过）

**扣分项**：每次和前章不衔接-2分，每次角色状态不延续-2分，每次设定矛盾-3分，每次信息矛盾-2分。

## 二、评分与等级

### 综合评分
```
综合评分 = 逻辑(20%) + 爽点(20%) + 节奏(10%) + 人物(15%) + 钩子(10%) + 去AI味(10%) + 合规(10%) + 上下文(5%)
```

### 等级
| 评分 | 等级 | 处理 |
|------|------|------|
| 9.0-10.0 | S级（神作） | 直接交付，可沉淀为模板 |
| 8.0-8.9 | A级（优秀） | 直接交付 |
| 7.0-7.9 | B级（良好） | 交付，有小改进空间 |
| 6.0-6.9 | C级（及格） | 需修改后交付 |
| 0-5.9 | D级（不及格） | 必须重写 |

### 通过条件
- 综合≥7.0分（B级及以上）
- 无任一维度≤4分（🔴致命问题）
- 合规维度≥7分

---

## 三、致命问题（🔴）判定

以下问题任一出现，直接判定为🔴致命问题，整章不通过，必须重写：

1. **机械降神**：绝境中突然出现没建立过的力量/人物/道具解决问题
2. **人设崩塌**：核心角色的言行严重违反人物表（性格/动机/红线）
3. **设定矛盾**：正文内容和已建设定文档严重冲突
4. **逻辑断裂**：主要事件的因果链完全不成立
5. **合规红线**：触碰政治/色情/血腥/犯罪教程等绝对红线
6. **严重抄袭**：和对标作品的具体桥段/台词/设定组合高度雷同
7. **严重AI味**：整章都是模板化结构/AI套话/均匀句式，读起来像机器写的
8. **朱雀AI率>40%**：朱雀检测整体AI率超过40%，或单段超过60%

---

## 四、全局一致性审查（每5章触发）

每写完5章，触发一次全局审查：

1. **设定一致性**：5章内的设定有没有前后矛盾？
2. **伏笔追踪**：埋了的伏笔有没有按计划回收？有没有遗忘的伏笔？
3. **人设漂移**：角色有没有慢慢偏离人物表？（说话方式变了/性格变了）
4. **时间线**：5章的时间线有没有穿帮？
5. **角色状态**：各角色的位置/身体/心理状态有没有不连贯？
6. **爽点节奏**：5章的爽点分布是否均匀？有没有连续3章没大爽点？
7. **主线推进**：5章推进了多少主线？有没有原地踏步？

全局审查发现问题→修正最近章节→更新追踪文件→继续。

## 五、细纲级全局审查（超过30章的长篇必做）
> 单章八维审查发现不了结构性问题。细纲级全局审查专门抓"卷级重复、节奏崩盘、角色消失、后期无敌、伏笔烂尾"等长篇通病。

### 5.1 审查维度（12维度）
| 维度 | 查什么 | 常见问题 |
|------|--------|----------|
| 1. 卷级冲突 | 每卷是否有独立的核心冲突和高潮？ | 某卷没有独立冲突，变成过渡卷 |
| 2. 节奏曲线 | 全书情绪曲线是否有起伏？ | 连续多卷压抑/连续多卷爽 |
| 3. 角色存在 | 主要角色是否每卷都有戏份？ | 配角中间几百章消失 |
| 4. 能力进化 | 主角能力升级节奏是否合理？ | 前期升级太慢/后期无敌 |
| 5. 反派强度 | 反派强度是否随主角成长？ | 反派降智/反派太强无法战胜 |
| 6. 伏笔回收 | 伏笔是否按计划回收？ | 伏笔埋了几百章不收/突然想起 |
| 7. 时间线 | 跨卷时间线是否穿帮？ | 角色年龄/事件时间矛盾 |
| 8. 设定一致 | 前后设定是否矛盾？ | 力量体系前后不一致 |
| 9. 重复检查 | 不同卷是否有重复的剧情模式？ | 第8卷和第10卷打同一个boss |
| 10. 越界检查 | 某卷是否把后面卷的内容提前了？ | 第8卷就打最终boss |
| 11. 情感线 | 主角情感线是否有推进？ | 女主中间几百章消失 |
| 12. 结局铺垫 | 结局是否有足够铺垫？ | 结局突兀/机械降神 |

### 5.2 致命问题判定
1. 卷级重复：两卷核心冲突/高潮高度相似
2. 内容越界：某卷把后面卷的关键内容提前
3. 角色消失：主要角色连续超过3卷（90章）无戏份
4. 后期无敌：主角某卷后没有对手，失去张力
5. 伏笔烂尾：核心伏笔超预计回收50章以上未回收
6. 节奏崩盘：连续3卷无大高潮或连续3卷都是高潮
7. 结局突兀：最终决战无足够铺垫，靠机械降神

### 5.3 多轮审查机制
- 第一轮：12维度逐卷审查，每卷至少3个真正问题（不凑数）
- 第二轮：聚焦结构性问题（重复/越界/节奏），深入挖掘
- 第三轮：修正后回查，确认问题已解决且无新问题
- 每轮必须有新发现，没有新问题说明审查不够深入

## 六、全新读者视角审查法（长篇必做，三轮迭代）
> 来源：实战中发现，常规审查（作者视角）会有"知识盲区"——作者知道设定所以不觉得矛盾，但新读者不知道。全新读者视角审查专门抓这种问题。
> 核心原则：假装第一次接触这个项目，不记得任何之前的设定，只看文件表面内容。以"读者能不能看懂""有没有矛盾""信息够不够"为标准。

### 6.1 三层自洽检查（必须全部通过）
| 层级 | 查什么 | 常见问题 |
|------|--------|----------|
| 第一层：文件内自洽 | 单个文件内部有没有矛盾 | 同一文件内力量等级前后不一/时间线混乱/元注释混入 |
| 第二层：文件间自洽 | 世界观/大纲/细纲/人物表之间有没有矛盾 | 大纲说F→D但世界观写F→B/人物表能力和细纲不一致 |
| 第三层：读者体验自洽 | 新读者读的时候会不会困惑/出戏 | 角色突然有力量没铺垫/情感线突兀/信息释放顺序不对 |

### 6.2 全新读者视角审查清单（20项）
**A. 明显矛盾（第一轮找）**
1. 力量等级：人物表/大纲/世界观/细纲四处的等级是否一致？
2. 时间线：世界观时间线/大纲卷时间/细纲章节时间是否对齐？
3. 角色死亡：大纲说某卷死，细纲是不是提前/延后死了？
4. 角色能力：人物表写的能力和细纲中使用的能力是否一致？
5. 元注释：细纲/大纲中有没有"精简为对话""不是100章"这类给作者的备注？
6. 章名：有没有过长（>10字）/过短（<2字）/重复的章名？
7. 爽点：有没有标注"爽点：无"的章节？（番茄每章必须有看点）

**B. 深层自洽（第二轮找）**
8. 背景时间：故事发生在"诡异降临后第X年"，角色的年龄/经历是否匹配？
9. 战力逻辑：主角当前等级能不能对抗当前敌人？不能的话有没有说明特殊方法？
10. 净化/转化规则：使用时是否符合已建立的规则（同级/高一级/需要辅助）？
11. 人口/资源：末世中的人口变化、食物、通讯是否合理？
12. 角色背景：主要角色诡异降临前的经历是否有交代？加入当前组织的原因？
13. 反派动机链：反派从出场到失败，每一步行动是否有合理动机？
14. 伏笔间隔：伏笔埋设和回收之间是否有足够间隔（不能刚埋就收，也不能埋了忘）？

**C. 结构/情感（第三轮找）**
15. 情感线节奏：主角感情发展是否有足够铺垫？确认关系的场景是否有情感积累？
16. 角色高光铺垫：角色突然展示强大力量/能力，之前是否有暗示？
17. 卷级结构：每卷的开头是否是"新冲突的开始"而不是"上一卷的余波"？
18. 信息释放：关键设定是否通过事件/对话透露，而不是旁白解说？
19. 新角色引入：新角色出场是否有足够的介绍（身份/能力/动机）？
20. 结局铺垫：重大转折/结局是否有至少3章以上的铺垫？

### 6.3 三轮迭代执行法
- **第一轮（明显矛盾）**：逐项检查A类7项，找"一眼能看到的矛盾"。目标：每10章至少1个问题。
- **第二轮（深层自洽）**：逐项检查B类7项，找"读了几十章后才发现的设定问题"。目标：每卷至少2个问题。
- **第三轮（结构/情感）**：逐项检查C类6项，找"读者体验层面的问题"。目标：每3卷至少1个问题。
- 每轮必须有新发现，没有新问题说明审查不够深入（假装得不够"新"）。
- 三轮合计问题数应≥30个（600章长篇），全部修正后才算通过。

### 6.4 实战案例（从真实审查中提炼）
| 问题类型 | 真实案例 | 修正方法 |
|----------|----------|----------|
| 文件间矛盾 | 大纲第1卷写F→B，升级表写F→D | 统一为F→D，全局搜索确认 |
| 时间线混乱 | 异界1天=1年，但30章后只过了1年 | 修正为"异界约12天=原世界1年" |
| 战力矛盾 | D级主角对抗四阶诡异 | 补充"非硬刚，用陷阱+削弱+地形" |
| 情感突兀 | 确认关系只有3句话 | 在觉醒章增加肢体接触铺垫，确认章增加细节 |
| 力量无铺垫 | 配角突然SSS级 | 在前50章添加"袖口有黑色纹路"的暗示 |
| 卷级结构错误 | 第5卷第1章就是"余波（战斗已结束）" | 改为"出发"，重新对齐大纲 |
| 背景时间矛盾 | 角色"三年前被感染"但诡异降临才1年 | 改为"诡异降临后被感染" |
| 能力不一致 | 人物表写"永久复制"，细纲写"速度" | 全局搜索统一能力名称 |

## 七、审查输出格式

```
【第X章内容审查报告】

综合评分：XX/10（[等级]）
审查结论：[通过/不通过]

八维得分：
1. 逻辑自洽：XX/10 — [一句话评价]
2. 爽点充足：XX/10 — [一句话评价]
```
