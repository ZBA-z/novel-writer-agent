# 钩子技法（Hook Techniques）

> 用途：章首钩子7式+章尾钩子13式+段落级钩子，确保章章有钩子，读者忍不住点下一章。
> 核心原则：钩子不是"为留钩而留钩"，钩子必须紧扣爽点方向和主线推进。一个让读者不关心的悬念不是好钩子。

---

## 一、章首钩子7式

章首钩子的目标：前100-200字让读者立刻进入状态，不回顾前情，不环境描写，不心理独白。

### 第1式：高能画面
直接给一个视觉冲击强烈的画面。
- 示例："血月之下，一只手从废墟里伸出来，攥着半块发霉的饼。"
- 适用：末世/玄幻/战斗/恐怖题材
- 要点：画面要有反常感（正常情况下不会出现的画面）

### 第2式：冲突现场
直接进入冲突最激烈的瞬间。
- 示例："'你被开除了。'经理把文件摔在桌上，'签字，现在就滚。'"
- 适用：都市/职场/校园/任何有冲突的题材
- 要点：冲突要具体（一句话/一个动作），不是"他们吵了起来"

### 第3式：反常悬念
一个不合常理的陈述，让读者想知道为什么。
- 示例："我死后的第三天，自己推开了家门。"
- 适用：灵异/重生/系统/悬疑/任何有超自然元素的题材
- 要点：反常程度越高，钩子越强，但后面必须能圆上

### 第4式：灵魂提问/判决
一句直击人心的话，通常是角色对主角说的。
- 示例："'你有罪。''凭什么？''凭你还活着。'"
- 适用：审判/复仇/道德困境/悬疑
- 要点：提问要有冲击力，不是"你吃饭了吗"这种日常问题

### 第5式：倒计时/绝境
主角处于极端困境，时间紧迫。
- 示例："距离毒气扩散还有三分钟。门被锁死了。林默摸遍全身，只有一根回形针。"
- 适用：逃生/解谜/战斗/任何有时间压力的场景
- 要点：困境要具体（时间/资源/障碍），让读者感受到紧迫

### 第6式：身份反差
一个和角色身份不符的场景或行为。
- 示例："全市最年轻的亿万富翁，此刻正在垃圾桶里翻半瓶矿泉水。"
- 适用：都市/逆袭/扮猪吃虎/身份隐瞒
- 要点：反差越大钩子越强，后面要解释为什么

### 第7式：结果前置
先告诉读者结果，再倒回去讲过程。
- 示例："林默赢了。但他赢得比死还难受。"
- 适用：任何题材，尤其是有反转的章节
- 要点：结果要有悬念（赢了为什么难受？），让读者想知道过程

## 二、章尾钩子13式

章尾钩子的目标：在读者情绪最高点时切断，让读者必须点下一章。钩子在章节最后100-200字。

### 第1式：危机悬停
危险已经发生但还没结果，黑屏。
- 示例："刀已经落下。林默闭上了眼。"
- 要点：危险必须是真实的（读者相信主角可能受伤/失败），不是假危机

### 第2式：反转
一个颠覆读者认知的事实。
- 示例："'你以为他是废物？'长老的声音在发抖，'他是...三年前消失的那位。'"
- 要点：反转必须有伏笔（之前有暗示），不是硬转

### 第3式：信息炸弹
揭露一个改变全局的信息。
- 示例："那封信上写着：你爹不是你爹。"
- 要点：信息必须和主角/主线密切相关，不是无关的八卦

### 第4式：选择困境
主角面临两个都不好的选择。
- 示例："救她，还是救全城？林默的手停在半空。"
- 要点：选择必须有代价（选A失去B，选B失去A），不是明显有正确答案

### 第5式：新角色/新势力登场
一个强大的/神秘的角色或势力出现。
- 示例："门被推开。一个穿着黑袍的人走进来，脸藏在阴影里。'终于找到你了，纪元调和者。'"
- 要点：新角色必须有压迫感或神秘感，不是路人甲

### 第6式：能力暴走/异变
主角或某人的力量失控/变化。
- 示例："林默胸口的纹路开始剧烈闪烁，黑色的能量不受控制地外泄。他感觉到，有什么东西在体内苏醒。"
- 要点：异变必须有后果（危险/未知），不是"力量变强了"这么简单

### 第7式：身份暗示
不直接揭露身份，但给一个强烈暗示。
- 示例："那人摘下兜帽。林默看到他左眉尾的旧疤——和自己一模一样的旧疤。"
- 要点：暗示要足够明显让读者猜到，但不说破，留到下一章揭晓

### 第8式：背叛/信任崩塌
主角信任的人背叛了。
- 示例："剑从背后刺穿了林默的胸口。他回头，看到的是最信任的兄弟的脸。'为什么？''因为你挡路了。'"
- 要点：背叛必须有铺垫（之前有异常迹象），不是突然背叛

### 第9式：规则打破
世界的规则被打破，一切都变了。
- 示例："天空裂开了。不是比喻——是真的裂开了，像一块碎掉的玻璃。林默看到裂缝后面，有无数双眼睛在看着他。"
- 要点：规则打破必须影响全局（不是只影响一个场景）

### 第10式：时间跳跃/预告
直接跳到未来的一个画面，让读者想知道怎么到那一步。
- 示例："三个月后。林默站在尸山之上，脚下是曾经的宗门。他不记得自己是怎么走到这里的。"
- 要点：未来画面必须和现在有巨大反差，让读者好奇中间发生了什么

### 第11式：道具/线索发现
发现一个改变局势的道具或线索。
- 示例："在尸体的口袋里，林默摸到一块铜牌。铜牌背面刻着两个字：'小心'。字迹，是他爹的。"
- 要点：道具/线索必须和主线/伏笔相关，不是无关物品

### 第12式：数字/倒计时
一个具体的数字或时间，制造紧迫感。
- 示例："'系统提示：宿主生命剩余24小时。'"
- 示例："'距离封印解除，还有七天。'"
- 要点：数字必须有后果（时间到了会发生什么），不是无意义的数字

### 第13式：情感暴击
一个直击情感的瞬间，不是悬念但让读者放不下。
- 示例："林默把那半块饼放在墓碑前。'娘，我找到仇人了。'风把饼吹走了。他站了很久。"
- 要点：情感必须有铺垫（之前建立了情感连接），不是突然煽情

## 三、段落级钩子

不只是章首章尾，章节中间也要有小钩子，让读者一直读下去。

### 段落钩子类型
1. **转折钩子**：一段结束时情况突然变化（"但他错了"）
2. **悬念钩子**：一段结束时抛出一个问题（"门后面是什么？"）
3. **信息钩子**：一段结束时透露一点信息但不说全（"他终于明白了——但已经晚了"）
4. **情绪钩子**：一段结束时情绪突然转折（"他笑了。笑得比哭还难看"）

### 使用频率
- 每300-500字至少一个段落钩子
- 爽点爆发前用钩子积累期待（"他不知道，接下来发生的事会改变一切"）
- 场景切换时用钩子连接（"他不知道的是，在另一个地方，有人正在谈论他"）

---

## 四、钩子使用原则

1. **钩子必须紧扣主线**：和主线无关的悬念读者不关心。"明天会不会下雨"不是好钩子，"明天封印会不会解除"是
2. **钩子必须有回应**：章尾钩子最好在下一章前500字内回应，不要拖太久（读者会忘）
3. **钩子不能假**：不要用"主角死了"结果下一章"原来是梦"——欺骗读者=流失读者
4. **钩子类型要变化**：不要每章都是"危机悬停"，13式轮换使用
5. **大钩子和小钩子配合**：每章有小钩子（章尾），每3-5章有大钩子（身份揭露/重大反转/新势力）
6. **钩子不要太多**：一章1个章尾钩子+几个段落钩子足够，太多钩子=没有钩子（读者麻木）

## 五、钩子质量自检

- [ ] 章首用了7式中的一种？
- [ ] 章首前100-200字进入状态？（没有回顾前情/环境描写/心理独白）
- [ ] 章尾用了13式中的一种？
- [ ] 章尾钩子紧扣主线/爽点方向？
- [ ] 钩子是真实的？（不是假危机/梦/幻觉）
- [ ] 钩子在下一章有回应计划？
- [ ] 段落中有小钩子？（每300-500字一个）
- [ ] 钩子类型有变化？（不是每章同一种）

## 六、章节命名方法论
> 番茄章节名影响点击率。好的章节名=内容概括+钩子，让读者看到名字就想点进去。

### 6.1 章节名的作用
1. **概括内容**：让读者知道这章大概讲什么
2. **制造悬念**：留一半不说，让读者好奇
3. **暗示爽点**：让读者期待这章的爽点
4. **保持连贯**：章节名之间有逻辑递进

### 6.2 章节名类型（8种）
| 类型 | 公式 | 示例 |
|------|------|------|
| 悬念式 | "XXX竟然XXX" | "系统竟然是她" |
| 反转式 | "本以为XXX，结果XXX" | "本以为是废物，结果是大佬" |
| 冲突式 | "XXXvsXXX" | "林默vs规则鬼" |
| 爽点式 | "XXX时刻" | "打脸时刻" |
| 身份式 | "XXX的真实身份" | "苏晚的真实身份" |
| 危机式 | "XXX危机" | "灭世者降临危机" |
| 情感式 | "XXX的XXX" | "老周的最后一碗红烧肉" |
| 数字式 | "第X次XXX" | "第三次献祭" |

### 6.3 章节名命名原则
1. **不剧透**：不要把章尾最大的反转直接写在标题里
2. **不太长**：控制在10字以内，太长手机端显示不全
3. **有钩子**：留悬念，不要"第X章：大家一起吃饭"这种白开水
4. **和内容相关**：标题党（标题和内容无关）会被读者骂
5. **风格统一**：全书章节名风格一致（都用悬念式/都用四字短语）

### 6.4 章节名正反例
**❌ 差的章节名**：
- "第三章"（没有信息量）
- "林默去了管理局"（白开水，没有钩子）
- "震惊！林默竟然是SSS级天才！"（标题党，剧透）

**✅ 好的章节名**：
- "管理局的内鬼"（悬念：谁是内鬼？）
- "陈锋的打火机"（细节钩子：打火机有什么问题？）
- "这波不亏"（主角口头禅，暗示爽点）
- "规则：不能回头"（直接点出本章核心冲突）

### 6.5 批量命名技巧
写细纲时一起起章节名，不要写完正文再补。每章细纲的"核心事件"提炼成章节名：
- 核心事件是"林默被管理局带走调查"→章节名"被带走的人"
- 核心事件是"陈锋暴露内鬼身份"→章节名"打火机上的标志"
- 核心事件是"林默献祭系统升级"→章节名"净化"
